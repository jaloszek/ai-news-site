### Coding Agents

- 🛠 **[v1.7.0](https://github.com/earendil-works/pi/releases/tag/v1.7.0)** — _Pi releases_. — Pi 1.7.0 reopens your last session after a terminal restart, with its original profile, tool limits and instructions.
  - Image generation runs in codemode via Radius or OpenRouter image models
  - Copilot prompt cache survives thinking-level changes on Claude 5.x and GPT-6
  - Install telemetry removed, along with the PI_TELEMETRY setting
- 🛠 **[v2.4.2](https://github.com/anomalyco/opencode/releases/tag/v2.4.2)** — _OpenCode releases_. — GPT-6.2 Sol, Astra and the gpt-latest aliases now start from a system prompt written for GPT-6.2.
  - Esc on an empty composer returns your message, images included
  - Always allow on a web fetch now permits that site only
  - generate_image and generate_video move into Code Mode, about 700 tokens lighter
- 🛠 **[How to choose the next safe step in application modernization](https://github.blog/ai-and-ml/github-copilot/how-to-choose-the-next-safe-step-in-application-modernization/)** — _GitHub AI blog_. — Evidence-first modernization runbook: inventory what still works, then pick the least disruptive fix, shipped as the doc-and-modernize Copilot skill.
  - Decision order: keep, upgrade, swap, wrap, rewrite only with evidence
  - Safety levels L0–L4 state the strongest honest regression net
  - PiggyMetrics: Java 8 to Java 21, nine modules to seven

### AI World

- 📝 **[Inside the AI Training Data Market — Gabe Greenberg, G2i](https://latent.space/p/inside_the_ai_training_data_market_gabe_greenberg_g2i/)** — _Latent Space (swyx)_. — G2i went from $15M to a projected $100M in training-data work without raising venture money.
  - Labs pay more for exclusive data, less if rivals can also buy it
  - Tasks must sit just ahead of the model; too hard and they become evals
  - Pilots cost frontier labs a few million dollars before any real order
- 📰 **[Chinese and North Korean state hackers add ARTEX AI framework to their arsenal](https://www.helpnetsecurity.com/2026/11/27/artex-ai-pentest-framework-china-north-korea-state-hackers/)** — _Help Net Security AI_. — Microsoft says ARTEX agents can go from a first scan to privileged access in minutes, not weeks.
  - The open-source tool appeared in July; its author pulled the code in October
  - Forks keep circulating, and ThreatBook now sells an ARTEX Pro build
  - One campaign logged 151,000 failed sign-ins, peaking at 2,900 a minute
- 📰 **[Anthropic wants to catch rogue AI activity without retaining your data](https://www.helpnetsecurity.com/2026/11/25/anthropic-enterprise-frontier-safeguards-public-beta/)** — _Help Net Security AI_. — Anthropic's new beta spots misuse patterns across many requests while the conversation data stays in the customer's cloud.
  - Safety Cases hold findings but neither prompts nor responses, pulled via API
  - Older zero-retention checks judged each request in isolation
  - Live on Claude Platform, AWS and Google Cloud; Microsoft Foundry is next
- 📰 **[Three studies from Meta and AMI Labs back Yann LeCun's bet on JEPA world models over large language models](https://the-decoder.com/three-studies-from-meta-and-ami-labs-back-yann-lecuns-bet-on-jepa-world-models-over-large-language-models/)** — _The Decoder_. — LeCun's AMI Labs, which raised over $1 billion, published three JEPA studies covering separate pieces of the world-model bet.
  - Results span robot planning, more efficient training and error correction
  - They remain separate pieces, not yet one working system
  - The work also maps where physics still sets limits
- 🟡 **[Taking Trainium3 to the Track: Generating Videos with LTX-2.5](https://huggingface.co/blog/video-trainium3)** — _Hugging Face blog_. — A month on an AWS Trainium3 box ended with 10-second AI video clips generating in 22 to 23 seconds.
  - That is roughly the LTX API's 23.7 s, on half the machine
  - The first working attempt took 5 min 20 s at under half the resolution
  - Video decode alone dropped from 357 s to 1.6 s

### Community

- 📝 **[How to scan agent skills for security risks with Tessl](https://tessl.io/blog/how-to-scan-agent-skills-for-security-risks-with-tessl)** — _Tessl blog_. — Walks through Tessl's Snyk-powered skill scanning — inventorying repo skills, failing CI on High or Critical findings, and setting install policies — starting from Snyk's 76 malicious payloads across 3,984 public skills.
- 🧪 **[OS-Omni: Benchmarking Generalist Computer-Using Agents on Long-Horizon Workflows Across Platforms](https://huggingface.co/papers/2611.34232)** — _HF Daily Papers_. — OS-Omni is a live benchmark that runs computer-using agents on long-horizon workflows across six environments, including Windows, Ubuntu and mobile.
  - v1 has 48 tasks per platform plus 12 desktop-and-phone workflows
  - Tasks average 67.54 interaction steps, versus 15.0 for OSWorld
  - Claude Opus 5.5 leads at 68.5% success against a 77.3% human reference
  - Agents beat humans on Linux but trail by over 25 points on iOS and macOS
- 📝 **[How Clay Builds GTM Agents — Jeff Barg, Head of AI](https://latent.space/p/how-clay-builds-gtm-agents-jeff-barg-head-of-ai/)** — _Latent Space (swyx)_. — Clay rebuilt Sculptor as a coding agent on the Pi harness; qualifying all 40 million companies costs about $1,500.
  - Usage is already near 50/50 between Clay's agent and outside harnesses like Claude Code
  - An automatic router ships soon because customers complain about the model selector
- 📰 **[OpenAI may be in cost control mode](https://micjm.com/blog/openai-is-in-cost-control-mode/)** — _Hacker News (points)_. — micjm reads GPT-6.2's Astra and Sol as cost-tuned, with reasoning and output tokens per task down against matched opponents in its Agent Duel battles.
  - Output-token drop p-values: 0.0055 for Sol, 0.022 for Astra
  - Reasoning-token drop p-values: 0.00013 for Sol, 0.0064 for Astra
  - Astra 6 and Sol 6.1 look normal; the 6.2 pair are underthinking outliers
- 📰 **[Google releases Cogentic papers on integer factorization, discrete logs and more](https://github.com/google-research/google-research/tree/master/cogentic_research_papers)** — _Hacker News (points)_. — Google Research posted six Cogentic-generated math papers in one commit, none peer-reviewed, with Lean formalizations promised later.
  - Headline claim is unconditional integer factorization in time L[1/3, 105]
  - Another claims Harary's 1964 edge-reconstruction conjecture for linear-density graphs
  - Cogentic runs on Gemini 4 from a problem statement with no expert hints
  - Google's repo says it is "not an official Google product"

### Newsletters

- 📧 **[DeepMind's Gemini agents discover quantum algorithms up to 290x cheaper, formally verified](https://arxiv.org/abs/2611.09822)** — _AlphaSignal · Nov 24_. — Teams of Gemini 4 agents cut resource costs across quantum algorithms, proving each result in Lean.
  - 290x faster arcsin routine; 2.57x speedup for an implementation of Grover's
  - Fusion simulation 11.8x cheaper, memory down from 5,650 to 4,338 qubits
  - Cytochrome P450 drug-metabolism simulation 2.5x cheaper, 481 to 333 qubits
  - Lean library, problem specs and verified solutions open-sourced on GitHub
- 📧 **[Thinking Machines drops 26B open-source model that runs on 16GB RAM](https://github.com/unslothai/unsloth)** — _AlphaSignal · Nov 23_. — Inkling 2 Mini is a 26.4B-parameter looped transformer with 3.4B active parameters.
  - Runs its middle layers three times per token; ~20GB native footprint
  - Scores 48.2% on DeepSWE v1.1, the maker's best under 100B parameters
  - Trained natively in NVFP4; GGUF builds ship via Unsloth and llama.cpp
  - Unsloth says the quantized build runs on 16GB RAM
- 📧 **[MCP servers can now ship skills, run tasks, and more with Claude (6 minute read)](https://claude.com/resources/articles/skills-over-mcp-tasks-and-more)** — _TLDR · Nov 26_. — Skills over MCP is in public beta, letting servers publish skills alongside their tools in Claude and Claude Code.
  - Tasks and Elicitation are now generally available
  - File Uploads, for PDFs, spreadsheets and images, is rolling out soon
  - Skills load only when needed and update with the server
