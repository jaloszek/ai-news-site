### Coding Agents

- 🛠 **[v2.1.293](https://github.com/anthropics/claude-code/releases/tag/v2.1.293)** — _Claude Code releases_. — v2.1.293 switches the default Haiku model to Claude Haiku 5.5 — 1M context at $0.10/$0.50 per Mtok.
  - Prompts over 100K tokens bill $0.50/$2.50 per Mtok
  - subagentStatusLine now carries agentType so scripts can tell subagent types apart
  - New isDeferred flag lists a tool's schema upfront instead of behind tool search
  - Fixes finished work being retracted or redone after context compaction
- 🛠 **[v1.1.0](https://github.com/earendil-works/pi/releases/tag/v1.1.0)** — _Pi releases_. — Pi 1.1.0 adds Claude Haiku 5.5 and lets supporting terminals report Pi's activity state.
  - OSC 7501 terminals show working, blocked, done, or failed; PI_PROGRAM_STATUS overrides detection
  - Claude Haiku 5.5 gets adaptive thinking up to xhigh/max effort plus Bedrock prompt caching
  - --tools +name/-name changes the default tool selection instead of replacing it
  - GPT-6 Luna and native llama.cpp classifiers available through the Decisions API
- 🛠 **[v1.18.35](https://github.com/anomalyco/opencode/releases/tag/v1.18.35)** — _OpenCode releases_. — Adds canonical redirects and JSON/Markdown stats formats for agent-readable output.
  - xAI tool results now include supported images and skip unsupported formats
  - Bumps @ai-sdk/xai to 3.0.139 and credits 3 community contributors

### AI World

- 📰 **[Claude Haiku 5.5 arrives with massive price cuts proving the AI pricing arms race is far from over](https://the-decoder.com/claude-haiku-5-5-arrives-with-massive-price-cuts-proving-the-ai-pricing-arms-race-is-far-from-over/)** — _The Decoder_. — Anthropic's Haiku 5.5 cuts small-model costs roughly 75% versus Haiku 4.5 and matches OpenAI's GPT-6 Luna pricing.
  - OSWorld computer-use score climbs from 15.7% to 72.4%
  - Terminal-Bench 4.0 hits 39.2%, where Haiku 4.5 scored zero
  - Input and output priced at $0.10 and $0.50 per million tokens
  - Sonnet 5.5 cache reads also halved, from $0.20 to $0.10
- 📰 **[Anthropic loosens Claude’s cyber restrictions for verified defenders](https://www.helpnetsecurity.com/2026/10/07/anthropic-expands-cyber-verification-program/)** — _Help Net Security AI_. — Anthropic rebuilt its Cyber Verification Program into three tiers, easing safety blocks for vetted defenders on Opus 5.5, Sonnet 5.5 and Mythos 5.1.
  - Defense Access covers incident response and malware analysis, with the broadest eligibility
  - Red Team Access adds authorized penetration testing, organizations only
  - Specialized Access has the fewest blocks, for critical systems like power grids
  - Real-time blocks stay on ransomware and high-risk safety systems
- 📰 **[Reka AI's omni-model Rho-1 handles text, images, video, and robot control in a single model](https://the-decoder.com/reka-ais-omni-model-rho-1-handles-text-images-video-and-robot-control-in-a-single-model/)** — _The Decoder_. — Reka released Rho-1, a 19B model handling text, images, video and robot control in one network, not a pipeline of specialists.
  - Runs all modalities as tokens in one shared context window
  - No tool calls or separate models needed
  - Trained on 320 H100 GPUs in about three months
  - A distilled 8-step variant returns a 5.3s clip in about a second
- 🟢 **[Sharing AI progress in mathematics](https://openai.com/index/sharing-ai-progress-in-mathematics)** — _OpenAI blog_. — OpenAI is publishing its frontier model's math results on GitHub with citation and revision protocols.
  - 722 manuscripts organized into 372 result families
  - Lean formalizations for many proofs, with more to come
  - 10 abridged summaries of the model's reasoning
  - About 4,000 problems attempted; average result roughly three hours of Pro thinking
- 📰 **[Anthropic is giving startups a free year of Claude Team and $1,000 in credits](https://techcrunch.com/2026/10/06/anthropic-gives-startups-a-free-year-of-enterprise-service-and-1000-in-token-credits/)** — _TechCrunch AI_. — Anthropic expanded its Claude Startups program, handing approved founders up to $7,000 in Claude products and credits.
  - A free year of Claude Team with up to five Premium seats
  - A one-time $1,000 API credit, available once approved
  - A new Startup Stack adds up to $45,000 in partner discounts and credits
  - Startups founded in the last five years, or funded in the last two, qualify
