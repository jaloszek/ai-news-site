# Thursday, July 2, 2026

### Coding Agents

- 🛠 **[v2.1.198](https://github.com/anthropics/claude-code/releases/tag/v2.1.198)** — _Claude Code releases_. — Claude in Chrome is now generally available, and background agents launched from claude agents now commit, push, and open a draft PR from their worktree instead of stopping to ask. A new /dataviz skill ships with a runnable color-palette validator, and the built-in Explore agent inherits the main session's model (capped at opus) instead of haiku.
- 🛠 **[Hermes Agent v0.18.0 (2026.7.1) — The Judgment Release](https://github.com/NousResearch/hermes-agent/releases/tag/v2026.7.1)** — _Hermes Agent releases_. — The Judgment Release closes every open P0 and P1 across the repo — 692 highest-priority items (496 issues, 196 PRs), zero remaining — while shipping first-class Mixture-of-Agents as a selectable model, /goal completion contracts that judge done-ness against evidence, and a /learn command that distills a reusable skill from a directory or URL.
- 🛠 **[v1.17.13](https://github.com/anomalyco/opencode/releases/tag/v1.17.13)** — _OpenCode releases_. — v1.17.13 forces reasoning mode for OpenAI-compatible reasoning models on custom deployments so reasoning settings apply reliably, and stops replaying stale GitHub Copilot response item IDs that were breaking follow-up requests — both Core bugfixes; the Desktop app also gains a searchable v2 model picker.

### AI World

- 📰 **[OpenAI reportedly cut response costs for guest ChatGPT users by more than half](https://the-decoder.com/openai-reportedly-cut-response-costs-for-guest-chatgpt-users-by-more-than-half/)** — _The Decoder_. — OpenAI told staff it cut inference costs by more than half for ChatGPT's guest (unauthenticated) traffic — the Nvidia GPUs serving those users dropped to just a few hundred — though it's unclear whether the gains carry to the full product, and Deepseek separately shipped an open-source method claiming 60-85% inference speedup.
- 📰 **[Claude Sonnet 5 continues Anthropic's pattern of hiding price increases behind unchanged token rates](https://the-decoder.com/claude-sonnet-5-continues-anthropics-pattern-of-hiding-price-increases-behind-unchanged-token-rates/)** — _The Decoder_. — Sonnet 5 scores 53 on Artificial Analysis' Intelligence Index (fifth, tied with GPT-5.5 high, six points over Sonnet 4.6) and beats the pricier Opus 4.8 on some agent tasks — but at the same $3/$15 list price it burns ~40% more output tokens per task at max, pushing real cost to $2.29/task versus Opus 4.8's $1.97 and nearly double Sonnet 4.6's $1.20.
- 🟡 **[Announcing our $800M Series C to accelerate the shift to open-source AI](https://www.together.ai/blog/announcing-our-series-c)** — _Together AI blog_. — Together AI closed an $800M Series C from NVIDIA, Aramco Ventures, and Vista Equity to scale open-weights inference, positioning itself as the cheaper alternative to closed frontier APIs — citing Decagon and Cursor among customers seeing 6x-20x lower costs as DeepSeek, GLM, and MiniMax narrow the quality gap.
- 🟡 **[Together AI at ICML 2026: frontier research across the full stack](https://www.together.ai/blog/icml-2026)** — _Together AI blog_. — Nine ICML 2026 papers from Together spanning the stack from agents down to GPU kernels — the standout is TTT-Discover, which matches prior best-on-record discovery results that previously needed closed frontier APIs, but with the open gpt-oss-120b for a few hundred dollars a problem.
- 📰 **[Wayve launches $85M employee tender offer at $8.5B valuation](https://techcrunch.com/2026/06/30/wayve-launches-85m-employee-tender-offer-at-8-5b-valuation/)** — _TechCrunch AI_. — Wayve is letting staff cash out $85M of vested equity at the $8.5B valuation it set in February's $1.2B Series D — its second tender since the 2024 Series C, and the latest in a wave of AI-startup secondaries (Decagon, ElevenLabs, Linear, Clay) pivoting from founder windfalls to a retention lever as the talent war makes comp vesting-this-minute a real flight risk.

**Reddit — AI World**

- 📝 **[How Cursor deploys AI inside the enterprise](https://www.latent.space/p/cursor-forward-deployed-engineers)** — _Latent Space (swyx)_. — Cursor VP of Forward Deployed Engineering Pauline Brunet outlines how her team embeds inside enterprises to build AI software factories — long-running agents spanning planning, coding, review and deploy — and is scaling the FDE org tenfold by December.

- 🧪 **[A Single Rewrite Suffices: Empirical Lessons from Production Skill Description Optimization](https://arxiv.org/abs/2606.30775)** — _arXiv cs.CL_. — An arXiv paper finds that a single LLM rewrite of skill descriptions — using false-positive and false-negative cases — matches manually tuned routing accuracy (79.2% vs 79.4% F1) while cutting per-skill engineering effort 32× (120 min to 3.8 min) on a 9-skill enterprise agent.
