# Friday, June 12, 2026

### Claude Code

- 🛠 **[v2.1.174](https://github.com/anthropics/claude-code/releases/tag/v2.1.174)** — _Claude Code releases_. — v2.1.174 adds a wheelScrollAccelerationEnabled setting for fullscreen mouse-wheel control and fixes the /model picker to show Opus as its own row on Max and Enterprise plans.
- 🛠 **[Making secret scanning more trustworthy: Reducing false positives at scale](https://github.blog/security/making-secret-scanning-more-trustworthy-reducing-false-positives-at-scale/)** — _GitHub AI blog_. — GitHub's secret scanning now routes candidate alerts through an LLM verification step adapted from Agentic Secret Finder, cutting false positives by over 75%.
- 🛠 **[v2.1.173](https://github.com/anthropics/claude-code/releases/tag/v2.1.173)** — _Claude Code releases_. — v2.1.173 normalizes Fable 5 model names by stripping the [1m] suffix automatically and silences a spurious sandbox warning on Windows.
