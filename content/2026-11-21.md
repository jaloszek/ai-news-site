### Coding Agents

- 🛠 **[v2.1.330](https://github.com/anthropics/claude-code/releases/tag/v2.1.330)** — _Claude Code releases_. — Adds Enterprise Admin Console org sign-in and easel, a built-in chart mod.
  - `claude auth login` applies the org's settings and uses its cloud provider or gateway
  - easel draws charts on request and under MCP metrics results; turn it off in `/config`
  - `CLAUDE_CODE_FULL_SIGN_IN_LINK=1` prints the full sign-in link
- 🛠 **[Release v0.28.3](https://github.com/QwenLM/qwen-code/releases/tag/v0.28.3)** — _Qwen Code releases_. — Adds GitHub as the third managed channel adapter, with no known breaking changes.
  - Explain background tasks from the composer chips in Web Shell
  - Generated UI cards keep view state across reloads, reopened conversations and forks
  - `/send` sends to another session; a Generic Webhook Channel posts JSON to an HTTPS endpoint
  - Mods are enabled in ACP sessions for `qwen --acp`, Zed and the VS Code companion
- 🛠 **[v1.6.0](https://github.com/earendil-works/pi/releases/tag/v1.6.0)** — _Pi releases_. — Makes GPT-6.2 Sol the default on openai, azure and openai-codex.
  - GPT-6.2 Astra and GPT-6.2 Sol are added to all three providers
  - `render()` now returns `readonly string[]`; extensions mutating output must copy first
  - Both reject reasoning effort `none` and `minimal`, so thinking level `off` is unavailable
  - Azure serves them at 1.05M context; Codex gives Sol 500K and Astra 272K

### AI World

- 🟢 **[Inside the Codex sandbox](https://openai.com/index/inside-the-codex-sandbox)** — _OpenAI blog_. — Codex runs shell commands inside each OS's own sandbox instead of a container, with network access off by default.
  - Writes allowed in the repo, while .git and .codex stay read-only
  - macOS uses Seatbelt, Linux bubblewrap plus seccomp, Windows is moving to Microsoft's MXC
  - The same profiles ship as a `codex sandbox` command for your own tools
- 🟢 **[Can AI help scientists identify promising drug candidates?](https://openai.com/index/introducing-medchembench)** — _OpenAI blog_. — OpenAI's new benchmark finds models read molecules well but still hesitate over which compound to make next.
  - 99 problems drawn from 117 papers and patents, 761 molecular structures
  - GPT-6.2 Astra took 84.5% of available credit, GPT-5.6 Sol just 58.2%
  - Rebuilding structures scored 95.4%; selecting compounds and predicting properties, about half
- 🔵 **[Genie 4 is now available on the Gemini API.](https://blog.google/innovation-and-ai/technology/developers-tools/genie-4-in-gemini-api/)** — _Google DeepMind_. — A day after its launch, Genie 4 is open to any developer: 720p interactive worlds from the Gemini API.
  - Continuous 720p at 24fps with synchronized native audio, dialogue included
  - Keyboard controls plus live text prompts change weather, lighting, objects
  - Ships through the Interactions API and Google AI Studio, SynthID watermarked
- 📰 **[Seven new models at scalable price-performance](https://microsoft.ai/news/microsoft-ignite-2026/)** — _Hacker News (points)_. — Microsoft is pitching its Ignite slate as an argument: near-frontier quality at a fraction of frontier cost.
  - MAI Code 2 hits 98% of GPT-6.1 Sol at 40% of the price
  - MAI Cyber 2 Flash beats GPT-6 Astra at under 2% cost per task
  - MAI Image 2.7 tops Artificial Analysis image editing at one-fifth the price

- 🎥 [Securing coding agents and their code | BRK281](https://www.youtube.com/watch?v=kKGX6P5VfZI) — **Microsoft Events** (46m46s). — A security playbook for teams whose coding agents now ship changes in minutes, aimed at platform and security leads.
  - Three controls: isolated sandboxes, supply-chain protections, automated validation of AI-generated code
  - Separates trusting the agent's runtime from trusting the code it writes
  - Microsoft Ignite breakout, advanced level; speakers Ricky Diep and Rohan Parakh

  - Start from the bounded context, then classify each capability by surface

### Community

- 📝 **[Fragments: November 20](https://martinfowler.com/fragments/2026-11-20.html)** — _Martin Fowler_. — CodeScene measurements say healthy code cost agents 22 to 35 percent less to review than unhealthy code.
  - Marcus Borg's experiment: 465 pull requests, 246 open source repositories, three LLMs
  - CodeHealth 2.8 for the unhealthy pull request against 9.7 for the healthy one
  - Complex Method and Complex Conditional smells drove most of the added cost
- 📝 **[Stop your docs drifting from your code: catch it on every change](https://tessl.io/blog/stop-your-docs-drifting-from-your-code-catch-it-on-every-change)** — _Tessl blog_. — Tessl's three-part series starts with a check that catches CLI README drift on every change.
  - A Node test compares the CLI's --help commands with README.md, in both directions
  - A Tessl verifier, a plain-English rule, judges behavior changes a script cannot
  - Part 2 adds a weekly sweep loop that opens a pull request when docs drift
- 🧪 **[Probing the "Conscious" Mind: Selective Access and Global Workspace in Vision-Language Models](https://huggingface.co/papers/2611.26590)** — _HF Daily Papers_. — Researchers introduce MC-Lens, a multimodal Jacobian lens with separate vision-encoder and language-decoder probes for tracking which concepts a VLM selects and shares across modalities.
- 📝 **[The War Against Slop and an Emerging Weapon to Fight it: Formal Verification](https://latent.space/p/formal-verification/)** — _Latent Space (swyx)_. — Richard MacManus argues formal verification is the correctness check AI-written code lacks, via &Truth's Clark Barrett.
  - Barrett: tests and scans find problems, but you are never sure you found all of them
  - Opus 5.5 hit a 50% solve rate on 36 small verification tasks, using about 40% fewer tokens than Opus 5
- 📝 **[Historic ANT IPO, Jensen wants back, Gemini Neon beats GPT 6.2 Sol/Astra & more AI news | ThursdAI Nov 19](https://sub.thursdai.news/p/historic-ant-ipo-jensen-wants-back)** — _ThursdAI_. — Anthropic's IPO priced at $83, raising over $80B in the largest listing on record.
  - Jensen Huang wanted back; Nvidia's board declined on the $115.8B earnings call
  - Arena and Artificial Analysis guests weigh Neon against Astra and Sol

### Newsletters

- 📧 **[CMU and Stanford get a 27B model to rewrite its own weights and grow smarter](https://arxiv.org/abs/2611.21885)** — _AlphaSignal · Nov 20_. — An open 27B model rewrote its own weights through reasoning alone, with no gradients and no training.
  - Its own edit made it 6.6 points more accurate on problems it never saw
  - Accuracy rose over eight consecutive self-rewriting sessions
  - It restored a damaged copy of itself to over 80% of the original accuracy
- 📧 **[SenseNova releases a 9B model that runs 56 layers deep by reusing weights](https://huggingface.co/sensenova/SenseNova-Loop-9B)** — _AlphaSignal · Nov 20_. — The 4-bit weights occupy about 4.9GB, and 256K-context inference needs roughly 15 GiB of GPU memory.
  - Layers 4–27 run twice; layers 0–3 and 28–31 run once
  - 512K context, text and image inputs, text output
  - AIDABench 65.31 versus 65.01 for the comparison model
  - Official AWQ 4-bit build available from launch day
- 📧 **[Microsoft releases open-source toolkit to stress-test generative AI safety](https://github.com/microsoft/PyRIT)** — _AlphaSignal · Nov 20_. — PyRIT 1.2.0 bundles a command-line scanner, the CoPyRIT browser GUI and an extensible Python framework.
  - Connects to OpenAI, Anthropic, Gemini, Bedrock, Hugging Face and Ollama targets
  - Built-in scenarios cover jailbreaks, data leakage, scams and cyber harms
  - MIT licensed; adaptive multi-turn attacks alongside human-led testing
