### Claude Code

- 🛠 **[v2.1.185](https://github.com/anthropics/claude-code/releases/tag/v2.1.185)** — _Claude Code releases_. — Stream-stall timeout doubled from 10s to 20s and the hint reworded from No response from API · Retrying in … to Waiting for API response · will retry in … — a UX polish, no behavioural change to retry logic.

### AI World

- 🟡 **[Beyond LoRA: Can you beat the most popular fine-tuning technique?](https://huggingface.co/blog/peft-beyond-lora)** — _Hugging Face blog_. — Hugging Face benchmarked six PEFT methods on equal footing and found LoRA sits below the Pareto frontier on image generation — OFT scored 0.708 vs LoRA's 0.697 on dino similarity while using 9.01 GB of VRAM against LoRA's 9.97 GB — and switching techniques in the PEFT library is a one-line config change.
