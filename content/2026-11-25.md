### Coding Agents

- 🛠 **[v2.1.332](https://github.com/anthropics/claude-code/releases/tag/v2.1.332)** — _Claude Code releases_. — MCP servers can now ship skills (beta), and a new hook event can refuse a skill's inline shell commands.
  - Server skills show as `server:skill` in the / menu
  - Reads on a named pipe nothing writes to now fail after 20 seconds
  - Held messages from other sessions get an Always deliver option
  - Fixed freezes from unbounded hook output and flooding MCP servers
- 🛠 **[v2.4.0](https://github.com/anomalyco/opencode/releases/tag/v2.4.0)** — _OpenCode releases_. — OpenCode 2.4.0 gives the desktop app a built-in browser and timer- or cron-driven automations.
  - Imports sign-ins and browsing history from Chrome, Edge, Firefox or Safari, plus extensions from Chromium stores
  - The agent can read and drive the same pages without switching apps
  - Automations run a prompt, script or shell command on a timer, cron schedule or MCP event
  - The image tool is now `generate_image`; old permission rules map automatically
- 🛠 **[v1.45.0](https://github.com/OpenHands/OpenHands/releases/tag/v1.45.0)** — _OpenHands releases_. — v1.45.0 ships OpenHands Projects in Canvas behind an experimental flag and nests sub-agent conversations under their parent.
  - Project conversations move into the sidebar, with files and PRs beside the chat
  - Factories show their worklogs newest first and can be deleted from their own page
  - Also fixes a range of mobile, accessibility and settings bugs

### AI World

- 📰 **[Anthropic tops 700 million monthly MCP SDK downloads and expands the protocol for more autonomous AI agents](https://the-decoder.com/anthropic-tops-700-million-monthly-mcp-sdk-downloads-and-expands-the-protocol-for-more-autonomous-ai-agents/)** — _The Decoder_. — Two years after launch, MCP has passed 700 million monthly SDK downloads and now runs jobs in the background.
  - Tasks runs a long job on a server and reports back when done
  - Elicitation pauses a running process to ask for missing details
  - Skills over MCP, in public beta, load only when needed
  - File uploads for PDFs, spreadsheets and images are rolling out soon
- 📰 **[Amazon’s Decart acquisition is a bet on using software to narrow the silicon gap with Nvidia](https://techcrunch.com/2026/11/24/amazons-decart-acquisition-is-a-bet-on-using-software-to-narrow-the-gap-with-nvidia-in-the-ai-chip-race/)** — _TechCrunch AI_. — Amazon paid a reported $7.5 billion for Decart and wants the software, not the world models.
  - Decart Optimization Stack coaxes more performance out of Amazon's Trainium chips
  - Amazon has worked with Decart on Trainium since 2025
  - Anthropic reportedly tried to buy Decart in the same ballpark
  - Nvidia invested in a $300 million round at a $4 billion valuation
- 🧪 **[Antom 3-in-1 Transformer: A Payment Foundation Model](https://huggingface.co/papers/2611.25403)** — _HF Daily Papers_. — Ant International put a 7B-parameter foundation model into live card-payment fraud scoring and cut the overall loss rate 37.88% against its XGBoost baseline.
  - One model reads transaction sequences, tabular fields and user graphs
  - Roughly 1.7B of its 7B parameters activate per task route
  - With 25% of the labels it beats training from scratch on all labels
- 🔵 **[We’re launching Humanity’s First Exam and a Kaggle hackathon to test LLM reliability.](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/humanitys-first-exam/)** — _Google DeepMind_. — DeepMind's new exam asks whether models get everyday questions right every time, not just once.
  - 544 text and image prompts across 20 foundational capabilities
  - Leaderboard and technical report published with the launch
  - Three-week Kaggle hackathon runs through December 15
  - Prompts were chosen to expose blind spots, not sampled at random
- 🟡 **[v0.34.1rc0: [Perf][Qwen4Exp] Add SM100 TP=2 and TP=8 skinny GEMM plans (#69529)](https://github.com/vllm-project/vllm/releases/tag/v0.34.1rc0)** — _vLLM releases_. — Blackwell perf work keeps landing as perf-only tags: this one adds SM100 skinny GEMM plans for Qwen4Exp at tensor parallelism 2 and 8.
  - Same corner as last week's FlashInfer top-k swap, 1.30-2.25x faster long-context decode on GB300
  - Release notes carry the commit and sign-off only, no benchmark figures yet

### Community

- 📝 **[ExecuTorch-TensorRT: PyTorch Robot Policies at NVIDIA TensorRT Speed](https://pytorch.org/blog/executorch-tensorrt-pytorch-robot-policies-at-nvidia-tensorrt-speed/)** — _PyTorch blog_. — NVIDIA and Meta ship ExecuTorch-TensorRT, which runs TensorRT-compiled PyTorch robot policies without libtorch.
  - Within 4% of ONNX-TensorRT on a Jetson Orin Nano, in speed and memory
  - pi0.5 (3.6B) makes an action chunk in 467 ms where eager mode runs out of memory
  - Robot install drops to about 4.6 GB instead of 11 GB
- 📰 **[[AINews] Gemini 4 Neon marks GDM's full return as a Frontier Lab](https://latent.space/p/ainews-gemini-4-neon-marks-gdm-s-full-return-as-a-frontier-lab/)** — _Latent Space (swyx)_. — Gemini 4 Neon beats Astra and Fable on LiveBench, cuts the TS Rust benchmark runtime by 48.6%, and ranks #3 on Artificial Analysis's Intelligence Index at 61.
- 🟢 **[Perplexity and Intelligence](https://openai.com/index/perplexity-and-intelligence)** — _OpenAI blog_. — Jakub Pachocki argues perplexity should be the shared cross-lab yardstick, and proposes common limits labs commit not to cross.
  - OpenAI published numbers on a fixed internal-code set: GPT-3.5 ~0.99, GPT-4 ~0.91
  - Capabilities emerged below 0.8, with math breakthroughs at ~0.76
  - He expects the next transformative window around 0.68-0.7 log-perplexity
- 🧪 **[Rewirable Circuits in Transformers with Loom Attention](https://huggingface.co/papers/2611.30634)** — _HF Daily Papers_. — LoomFormer's loom attention lets a Transformer rewire its circuits per token, matching models trained with over 3x the compute.
  - Vertical attention over earlier heads runs through a per-token matrix memory, a second residual stream
  - Costs 2% extra FLOPs; LoomPythia-2.8B matches Pythia-12B at 0-shot and beats it at 5-shot
- 📝 **[Armin Ronacher and Mario Zechner on Coding With Agents](https://www.aihero.dev/armin-ronacher-and-mario-zechner-on-coding-with-agents~fn8vd)** — _AI Hero (Matt Pocock)_. — Mario Zechner tells Matt Pocock that agent verification is overrated, since agents measure the wrong thing and still cannot do system design.
