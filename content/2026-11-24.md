### Coding Agents

- 🛠 **[v2.1.331](https://github.com/anthropics/claude-code/releases/tag/v2.1.331)** — _Claude Code releases_. — Code Mode now runs in terminal sessions on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry and Claude Platform on AWS.
  - Added an API connectivity section to `claude doctor` that reports whether the API can be reached, with the HTTP status or the error
  - Fixed MCP tool calls hanging for up to 30 minutes on some malformed replies from a local or WebSocket server
  - Added `optionalDependencies` to plugin manifests: plugins that install with the plugin listing them and can be disabled or uninstalled on their own
- 🛠 **[0.172.0](https://github.com/openai/codex/releases/tag/rust-v0.172.0)** — _Codex releases_. — Codex 0.172.0 adds thread links, slash-command Tab completion and task-group navigation to the terminal CLI.
  - Follow thread links from search results and transcripts to open saved conversations and nested agents
  - `Tab` completes arguments for supported slash commands, e.g. `/mcp lo` to `/mcp login`
  - `Shift+Up` and `Shift+Down` jump between task groups in the agent command center
  - `codex exec resume` restores saved sandbox permissions, working directory and workspace roots
- 🛠 **[Release v0.28.4](https://github.com/QwenLM/qwen-code/releases/tag/v0.28.4)** — _Qwen Code releases_. — Qwen Code 0.28.4 adds built-in Gemini 4 reasoning defaults and a workspace artifact library in local daemon mode.
  - Artifact library scans the workspace progressively and streams updates
  - Web Shell chat gains a shared ChatSurface, Continue badges and suggestion chips
  - Local Runtime creates its state directory at spawn with owner-private permissions

### AI World

- 🟡 **[RoboTrack: Point tracking for real-world robotic manipulation](https://allenai.org/blog/robotrack)** — _Ai2 blog_. — The best point trackers lose 3.0 to 6.6 AJ when Ai2 scores them on real robot footage instead of RoboTAP.
  - CoWTracker drops from 70.5 to 63.9 on the 307-video RoboTrack-Bench
  - RoboTracker-Warp, retrained on synthetic data, recovers 2.1 AJ to 66.0
  - A pipetting test finished 17 of 20 trials versus 8 for object masks
- 📰 **[Anthropic launches Claude Ship, letting AI agents review, fix, and approve code changes](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)** — _TechCrunch AI_. — Anthropic is automating the step after code generation: Claude can now approve a pull request, not just write it.
  - Code Review is already generally available; PR Steward and Claude Approvals are still beta
  - PR Steward fixes failing CI checks, merge conflicts and review feedback
  - Approval rules live as a natural-language policy file inside the repository
- 📰 **[Anthropic's appetite for compute is pushing xAI toward a rent-over-build strategy](https://the-decoder.com/anthropics-appetite-for-compute-is-pushing-xai-toward-a-rent-over-build-strategy/)** — _The Decoder_. — xAI is turning into a GPU landlord: Anthropic now pays it roughly $3.1 billion a month, with Google at $800 million.
  - Either contract can be canceled with 90 days' notice
  - Musk pushed engineers in August for more revenue per GPU
  - The 60-person Grok Imagine team was told in November it would be disbanded
- 📰 **[Z.ai follows OpenAI into loop transformer territory with its new 750B flagship model](https://the-decoder.com/z-ai-follows-openai-into-loop-transformer-territory-with-its-new-750b-flagship-model/)** — _The Decoder_. — Z.ai retrained its GLM-5 base into a loop model, running 28 layers twice, as OpenAI has since GPT-6 Astra.
  - It claims 750B parameters perform like 2 to 3 trillion
  - Benchmarks so far come only from a 30B test model
  - AIME25 rose 19.2 to 30.4 in that test; GPQA-Diamond 47.6 to 56.3
  - Weights promised after safety testing; token pricing not announced
- 📰 **[Xalgorix: Open-source AI penetration testing tool](https://www.helpnetsecurity.com/2026/11/23/xalgorix-ai-penetration-testing-tool/)** — _Help Net Security AI_. — Xalgorix is an Apache-2.0 pen-testing agent whose verifier must re-exploit every finding before the report ships.
  - It drives Nmap, Nuclei and SQLmap through a 22-phase test plan
  - A scope guard blocks any host outside the configured targets
  - The verifier gets read-only tools, eight turns and three minutes per check
  - Claude Opus 5.5 gave the best results, but no benchmarks are published

### Community

- 📰 **[Fast-Anything: Don't rewrite it in Rust. Rewrite the 5% that's slow](https://github.com/EL4CTEO/fast-anything)** — _Hacker News (points)_. — EL4CTEO's fast-anything ports only an app's slowest functions to Rust, then replays recorded calls before enabling each port.
  - port records up to 500 real calls and builds a one-function Rust crate
  - Python fuzzy dedupe went from 4.91s to 42ms, 116x faster
- 🧪 **[Motion Mamba 2.0: Autoregressive Diffusion Mamba for Long-Horizon Humanoid Control](https://huggingface.co/papers/2611.29897)** — _HF Daily Papers_. — Motion Mamba 2.0 swaps bounded attention caches for a Mamba backbone so humanoid controllers keep distant history without paying repeated denoising.
- 📰 **[If you stop writing code, you also get worse at reviewing it](https://cekrem.github.io/posts/if-you-stop-writing-code-you-also-get-worse-at-reviewing-it/)** — _Hacker News (points)_. — Christian Ekrem argues that delegating all coding atrophies the review skill, since judging code depends on having written it.
  - Keep practicing, he says; reading AI output is not practice
- 📝 **[Ladybird's first alpha release](https://simonwillison.net/2026/Nov/23/ladybird/)** — _Simon Willison_. — Simon Willison installed Ladybird's first alpha without compiling it and calls the result very impressive. He still will not sign into GitHub or Gmail with it.
- 📰 **[Inkling 2 Mini](https://thinkingmachines.ai/news/inkling-2-mini/)** — _Hacker News (points)_. — The primary release page for Inkling 2 Mini, whose looped layers let the open model reason internally instead of writing more tokens.

### Newsletters

- 📧 **[Sashiko: Lessons from building an agentic code review system for Linux (11 minute read)](https://cloud.google.com/blog/products/application-development/lessons-from-building-sashiko-an-agentic-code-review-system)** — _TLDR · Nov 20_. — Google detailed Sashiko, its open-source Gemini code reviewer for Linux kernel patches.
  - Up to seven specialist sessions run in parallel, each on one bug class
  - About 1,200 reviews a day across more than 100 kernel mailing lists
  - 60-day post-merge fix rate fell to 2.2% in Linux 7.2
  - Sashiko is credited in 2,000+ mainline commits and 528 of 2026's kernel CVEs
- 📧 **[Google books a dedicated New Glenn launch in Q1 2029 for Project Suncatcher, its orbital TPU compute constellation (1…](https://www.blueorigin.com/news/google-selects-new-glenn-for-project-suncatcher)** — _TLDR · Nov 20_. — Google booked a dedicated New Glenn launch for Q1 2029 to put Project Suncatcher satellites in sun-synchronous orbit.
  - Each satellite carries roughly a data center rack's worth of compute capacity
  - Follows an October test that booted TPUs in orbit and sent a Gemma 4 haiku home
- 📧 **[Introducing agent controls: An enterprise control plane for agent behavior (10 minute read)](https://commandline.microsoft.com/introducing-agent-controls-an-enterprise-control-plane-for-agent-behavior/)** — _TLDR · Nov 20_. — Microsoft's agent controls is a managed Azure service that rules on agent actions at runtime, now in public preview.
  - Built on the open-source Agent Control Specification and Agent Hooks
  - Returns allow, deny, or transform, with a receipt naming the policy versions applied
  - Policies mix Content Safety classifiers, LLM judges, and Rego rules
