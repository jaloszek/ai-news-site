# Thursday, June 4, 2026

### Claude Code

- 🛠 **[waitingFor for agent blocking — CC v2.1.162](https://github.com/anthropics/claude-code/releases/tag/v2.1.162)** — `claude agents --json` now includes a `waitingFor` field showing what a session is blocked on. Also ships explicit Grep/Glob as `--tools` options on native builds and `/effort` confirmation when a level persists as default.
  - 20+ fixes: silent startup hang on unwritable config, WebFetch permission precedence over preapproved domains, Windows backslash/case-variant permission rules, LSP `workspaceSymbol` now accepts a `query` parameter, and `claude agents` status text no longer truncated on wide terminals.
  - Quieter startup — notices group by severity, failed turns show a compact warning, and the "Claude in Chrome enabled" startup message is removed.

- 📝 **[Introducing the Services Track and Partner Hub of the Claude Partner Network](https://www.anthropic.com/news/services-track-partner-hub)** — Anthropic launched a tiered partner program with a public directory and MCP connector for the Claude Partner Hub. Over 40,000 firms have applied since the $100M partner investment in March, with promotions processed semiannually. Partners can query their tier standing, deal status, and certification counts directly through the Claude MCP connector.

- 📝 **[Running an AI-native engineering org](https://claude.com/blog/running-an-ai-native-engineering-org)** — Fiona Fung, Director of Engineering for Claude Code and Cowork, details how the team replaced six-month roadmaps with JIT planning, shifted from "find the author" to "ask Claude first" for context, and hired for creative builders and deep systems engineers over raw throughput. The team now sees Claude-assisted commits as the default, with onboarding ramp time down to a week.

### AI World

- 🟢 **[Codex for every role, tool, and workflow](https://openai.com/index/codex-for-every-role-tool-workflow)** — _OpenAI blog_. — Codex rolls out six role-specific plugins — data analytics, creative production, sales, product design, investing, and investment banking — bundling 62 apps and 110 skills, plus shareable Sites for interactive dashboards and living reports.

- 🟢 **[How Wasmer used Codex to build a Node.js runtime for the edge](https://openai.com/index/wasmer)** — _OpenAI blog_. — Wasmer used OpenAI Codex with GPT-5.5 to build a Node.js edge runtime, reporting 10x to 20x development acceleration and shipping in weeks instead of months.

- 🟡 **[JetBrains releases Mellum2, a 12B open-source coding model that runs like a 2.5B](https://arxiv.org/abs/2605.31268)** — _AlphaSignal_. — Mellum2's MoE uses 64 experts with 8 active per token and a 131K context window, shipping six Apache 2.0 variants including a Thinking model scoring 69.9% on LiveCodeBench v6 — JetBrains trained from scratch on 10.6 trillion tokens with speculative decoding via a multi-token prediction head for IDE-speed inference.

- 🟡 **[Direct Preference Optimization Beyond Chatbots](https://huggingface.co/blog/Dharma-AI/direct-preference-optimization-beyond-chatbots)** — _Hugging Face blog_. — Dharma-AI used DPO to cut OCR text degeneration by 59.4% on average across five vision-language model families by training on the model's own degenerate outputs as rejection pairs — SFT alone had a structural ceiling on the failure mode that DPO's completion-level loss bypasses.

- 📧 **[Open-source 5B robot model trained on 27K hours learns to act and imagine at once](https://huggingface.co/sii-research/tau-0-wm)** — _AlphaSignal_. — The TAU-0-WM 5B-parameter robot model combines action prediction with world modeling from 27,000 hours of demonstration data, enabling both planning and execution in one architecture.

### Community

- 📧 **[Datalab releases Surya, a 650M open-source OCR model beating rivals under 3B params](https://github.com/datalab-to/surya)** — _AlphaSignal_. — Surya is a 650M-parameter OCR model that outperforms larger alternatives under 3B parameters, making high-accuracy text extraction feasible on consumer hardware.

- 📧 **[Two small models team up to fill forms that neither can complete alone](https://huggingface.co/nvidia/LocateAnything-3B)** — _AlphaSignal_. — NVIDIA's LocateAnything-3B uses two small specialized models working together to solve form-filling tasks that neither can handle independently, achieving results competitive with much larger systems.

- 📧 **[Nous Research ships Hermes Desktop, a native agent app for all platforms](https://github.com/NousResearch/hermes-agent/tree/main/apps/desktop)** — _AlphaSignal_. — Hermes Desktop provides a cross-platform native app for interacting with Nous Research's agent framework, bringing local AI agent capabilities to Windows, macOS, and Linux.

- 📧 **[ByteDance open-sources Bernini, a video generation and editing model that rivals top closed-source tools](https://huggingface.co/ByteDance/Bernini-R)** — _AlphaSignal_. — Bernini-R is ByteDance's open-source video generation and editing model that competes with proprietary tools like Runway and Pika, released on Hugging Face.
