# Thursday, June 4, 2026

### Claude Code

- 🛠 **[v2.1.162](https://github.com/anthropics/claude-code/releases/tag/v2.1.162)** — _Claude Code releases_. — Claude Code 2.1.162 adds waitingFor to agent --json output for viewing blocked sessions and restores Grep/Glob as explicit --allowedTools options on native builds — though the opt-in only works from CLI args, not from settings.json permission rules, so teams cannot persist the preference across projects without shell wrappers.

### AI World

- 🟢 **[Codex for every role, tool, and workflow](https://openai.com/index/codex-for-every-role-tool-workflow)** — _OpenAI blog_. — Codex rolls out six role-specific plugins — data analytics, creative production, sales, product design, investing, and investment banking — bundling 62 apps and 110 skills, plus shareable Sites for interactive dashboards and living reports.
- 🟢 **[How Wasmer used Codex to build a Node.js runtime for the edge](https://openai.com/index/wasmer)** — _OpenAI blog_. — Wasmer used OpenAI Codex with GPT-5.5 to build a Node.js edge runtime, reporting 10x to 20x development acceleration and shipping in weeks instead of months.
- 📧 **[NVIDIA ships open-weights text-to-image model as part of Cosmos 3 release](https://huggingface.co/nvidia/Cosmos3-Super-Text2Image)** — _AlphaSignal_. — Cosmos3-Super-Text2Image generates images from text prompts under permissive open weights on Hugging Face, joining NVIDIAs Cosmos 3 family of world foundation models for physical-world simulation.
- 📧 **[JetBrains releases Mellum2, a 12B open-source coding model that runs like a 2.5B](https://arxiv.org/abs/2605.31268)** — _AlphaSignal_. — Mellum2's MoE uses 64 experts with 8 active per token and a 131K context window, shipping six Apache 2.0 variants including a Thinking model scoring 69.9% on LiveCodeBench v6 — JetBrains trained from scratch on 10.6 trillion tokens with speculative decoding via a multi-token prediction head for IDE-speed inference.
- 🟡 **[Direct Preference Optimization Beyond Chatbots](https://huggingface.co/blog/Dharma-AI/direct-preference-optimization-beyond-chatbots)** — _Hugging Face blog_. — Dharma-AI used DPO to cut OCR text degeneration by 59.4% on average across five vision-language model families by training on the model's own degenerate outputs as rejection pairs — SFT alone had a structural ceiling on the failure mode that DPO's completion-level loss bypasses.

### Community

**Reddit — Local AI**

- 📧 **[Datalab releases Surya, a 650M open-source OCR model beating rivals under 3B params](https://github.com/datalab-to/surya)** — _AlphaSignal_. — Surya 2 scores 83.3% on olmOCR-bench (best in class under 3B params) and 87.2% across 91 languages, handling OCR, layout, and table recognition in one 650M model served by vllm or llama.cpp at 5 pages/s on an RTX 5090.

- 📧 **[ByteDance open-sources Bernini, a video generation and editing model that rivals top closed-source tools](https://huggingface.co/ByteDance/Bernini-R)** — _AlphaSignal_. — Bernini combines an MLLM-based semantic planner with a DiT renderer, scoring 4.04 overall on OpenVE-Bench ahead of Kling O3 and competitive with Wan2.7 — the weights ship on Hugging Face as a diffusers-format package built on Wan2.2.

**Reddit — Claude & Coding**

- 📧 **[Anthropic files confidential IPO paperwork with the SEC](https://www.anthropic.com/news/confidential-draft-s1-sec)** — _AlphaSignal_. — Anthropic's confidential S-1 filing follows a $65B Series H at a $965B valuation, targeting an October debut and putting it in a three-way IPO race with OpenAI and SpaceX.

**Reddit — AI World**

- 🧪 **[Agent Planning Benchmark: A Diagnostic Framework for Planning Capabilities in LLM Agents](https://arxiv.org/abs/2606.04874)** — _arXiv cs.CL_. — APB provides 4,209 multimodal planning cases across 22 domains to isolate whether LLM agent failures stem from planning or execution, addressing a gap in end-to-end agent evaluations.

- 📧 **[Two small models team up to fill forms that neither can complete alone](https://huggingface.co/nvidia/LocateAnything-3B)** — _AlphaSignal_. — NVIDIA open-sourced LocateAnything-3B, a vision-language grounding model that outputs all bounding boxes in one forward pass using Parallel Box Decoding, achieving 10x the throughput of Qwen3-VL while matching or surpassing 30B-parameter models on GUI benchmarks.

- 📧 **[Unsloth releases dynamic compression to run Gemma 4 12B more efficiently](https://huggingface.co/unsloth/gemma-4-12b-it-GGUF)** — _AlphaSignal_. — Unsloth released a dynamic-compression GGUF for Gemma 4 12B that cuts inference memory without retuning, letting the model fit on consumer GPUs with minimal quality loss.

- 📧 **[0xSero releases pruned 519B Kimi-K2.6 model optimized for code, math, and tool use](https://huggingface.co/0xSero/Kimi-K2.6-519B-NVFP4)** — _AlphaSignal_. — 0xSero pruned Kimi-K2.6 to a 519B NVFP4 model that retains strong code, math, and tool-use performance at roughly half the memory footprint of the full-precision version.

- 📧 **[Nous Research ships Hermes Desktop, a native agent app for all platforms](https://github.com/NousResearch/hermes-agent/tree/main/apps/desktop)** — _AlphaSignal_. — The Hermes Desktop public preview (v0.15.2) packages Nous Research's MIT-licensed agent into a native Electron UI with streaming tool output, preview panes, voice I/O, and five sandbox backends — for developers who wanted Hermes without living in the terminal.
