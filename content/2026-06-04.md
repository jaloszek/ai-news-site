# Thursday, June 4, 2026

### Claude Code

- 🛠 **[claude agents --json now shows waitingFor for blocked sessions](https://github.com/anthropics/claude-code/releases/tag/v2.1.162)** — Ships in v2.1.162. `claude agents --json` now includes `waitingFor` to surface what a waiting session is blocked on (e.g. a permission prompt), making it useful for scripting session pickers and status bars.

  - `--tools`: explicitly listing Grep/Glob now provides the dedicated search tools on native builds with embedded search (previously these names were silently ignored)
  - `/effort` now confirms when your chosen level will persist as the default for new sessions
  - Remote Control now shows as a persistent footer pill instead of a startup message; renamed Windsurf to Devin Desktop in `/ide` and `/terminal-setup`

- 🛠 **[Parallel tool calls: failed Bash no longer cancels the batch](https://github.com/anthropics/claude-code/releases/tag/v2.1.161)** — Ships in v2.1.161. A failed Bash command no longer cancels other tool calls in the same batch — each tool returns its own result independently. Also adds `OTEL_RESOURCE_ATTRIBUTES` as metric labels for slicing usage by custom dimensions, and `/mcp` now collapses claude.ai connectors you've never signed into.

- 🛠 **[Services Track and Partner Hub formalize Claude Partner Network](https://www.anthropic.com/news/services-track-partner-hub)** — Anthropic's Claude Partner Network adds a three-tier Services Track (Select/Preferred/Global Premier) and a public Partner Hub directory. Since the March launch with $100M backing, 40,000+ firms have applied and 10,000+ consultants earned certification, with Deloitte (470K), Cognizant (350K), KPMG (276K), and Accenture (30K) rolling out Claude enterprise-wide.

### AI World

- 🟢 **[Codex for every role, tool, and workflow](https://openai.com/index/codex-for-every-role-tool-workflow)** — _OpenAI blog_. — Codex rolls out six role-specific plugins — data analytics, creative production, sales, product design, investing, and investment banking — bundling 62 apps and 110 skills, plus shareable Sites for interactive dashboards and living reports.

- 🟢 **[How Wasmer used Codex to build a Node.js runtime for the edge](https://openai.com/index/wasmer)** — _OpenAI blog_. — Wasmer used OpenAI Codex with GPT-5.5 to build a Node.js edge runtime, reporting 10x to 20x development acceleration and shipping in weeks instead of months.

- 🟡 **[JetBrains releases Mellum2, a 12B open-source coding model that runs like a 2.5B](https://arxiv.org/abs/2605.31268)** — _AlphaSignal_. — Mellum2's MoE uses 64 experts with 8 active per token and a 131K context window, shipping six Apache 2.0 variants including a Thinking model scoring 69.9% on LiveCodeBench v6 — JetBrains trained from scratch on 10.6 trillion tokens with speculative decoding via a multi-token prediction head for IDE-speed inference.

- 🟡 **[Direct Preference Optimization Beyond Chatbots](https://huggingface.co/blog/Dharma-AI/direct-preference-optimization-beyond-chatbots)** — _Hugging Face blog_. — Dharma-AI used DPO to cut OCR text degeneration by 59.4% on average across five vision-language model families by training on the model's own degenerate outputs as rejection pairs — SFT alone had a structural ceiling on the failure mode that DPO's completion-level loss bypasses.

- 📧 **[Open-source 5B robot model trained on 27K hours learns to act and imagine at once](https://huggingface.co/sii-research/tau-0-wm)** — _AlphaSignal_. — The TAU-0-WM 5B-parameter robot model combines action prediction with world modeling from 27,000 hours of demonstration data, enabling both planning and execution in one architecture.
