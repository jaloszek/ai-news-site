### Coding Agents

- 🛠 **[Release v0.28.7](https://github.com/QwenLM/qwen-code/releases/tag/v0.28.7)** — _Qwen Code releases_. — Qwen Code 0.28.7 loads Claude Code 2.1.332 mods and moves the CLI onto the Harness kernel.
  - Usage statistics off by default unless privacy.usageStatisticsEnabled is set
  - Repeated-tool-call rejections now name the cause and suggest /compress or /clear
  - Breaking: Qwen no longer detects model loops or caps tool calls
  - Interactive CLI saves reasoning effort and context window per model
- 🛠 **[Hermes Agent canary canary.20261125T064800Z-v0.23.4](https://github.com/NousResearch/hermes-agent/releases/tag/canary.20261125T064800Z-v0.23.4)** — _Hermes Agent releases_. — Hermes Agent's November 25 canary ties each cron firing's delivery settings to that execution and refuses manual runs of paused jobs.
  - Cron plugin lookups are now profile-scoped
  - Delivery uses the firing job's snapshot, exposed as ctx.cron_delivery_platforms
  - ComfyUI no longer replays a submission after following a redirect
  - Desktop refuses macOS updates from read-only locations before quitting
- 🛠 **[v1.44.0](https://github.com/OpenHands/OpenHands/releases/tag/v1.44.0)** — _OpenHands releases_. — OpenHands 1.44.0 adds per-audience automation visibility and an editable key-value store for automations.
  - Conversation mentions ship behind the `conversation_mentions` flag
  - A Factories sidebar entry adds list and drill-in views
  - Hitting a budget now shows a readable error instead of failing opaquely
  - `agent-server` requirement moves to 1.63.1

### AI World

- 📰 **[Nvidia hits pause on chip shipments to Southeast Asia](https://techcrunch.com/2026/11/26/nvidia-hits-pause-on-chip-shipments-to-southeast-asia/)** — _TechCrunch AI_. — The US export squeeze now reaches the rented overseas data centres Chinese firms use to reach Nvidia chips.
  - Dell and Super Micro told to pause server shipments to Malaysia, Singapore, Thailand, Indonesia
  - Commerce reportedly closed the remote-access loophole earlier this month
  - Institute for Progress estimates such centres supply about 24% of China's AI compute
- 📰 **[Anthropic turns Claude Artifacts into standalone desktop apps for macOS and Windows](https://the-decoder.com/anthropic-turns-claude-artifacts-into-standalone-desktop-apps-for-macos-and-windows/)** — _The Decoder_. — Anthropic's Artifacts now install as real Mac and Windows apps, turning chat demos into things that live in the dock.
  - Beta as of today, needs the latest Claude desktop app; a free account is enough
  - Installed apps can add menu bar items, transparent windows and notifications
  - Optional full computer access lets them intercept shortcuts and float over other programs
- 🟡 **[Introducing the llama.cpp benchmark dashboard for AMD Ryzen and Radeon](https://huggingface.co/blog/ggml-org/llamacpp-amd-bench)** — _Hugging Face blog_. — The llama.cpp team now publishes its AMD benchmark runs on Hugging Face, replacing scattered forum numbers with a filterable dashboard.
  - Hardware list is just two Radeon chips: 8060S and AI Pro R9700S
  - Two tests: PP512 prompt processing and TG128 generation, in tokens/sec
  - Weekly runs use llama-bench with Flash Attention on and off, 10 reps
- 🟡 **[Where scientists draw the line on AI agents](https://allenai.org/blog/where-scientists-draw-the-line-on-ai-agents)** — _Ai2 blog_. — Ai2 asked 17 scientists what agents must prove in research and came back with five trust dimensions.
  - They are validation, privacy, objectivity, accountability and transparency
  - Several check agent answers against original papers, not summaries
  - Interviewees split between excitement and existential worry about scientists' role
  - Ai2 proposes benchmarks testing whether agents overlook conflicting evidence
- 📰 **[Claude AI can review pull requests and ship fixes on its own now](https://www.theverge.com/ai-artificial-intelligence/1040134/anthropic-claude-ship-ai-pull-requests)** — _The Verge AI_. — Claude's code review now has hands: Claude Ship lets it fix a pull request and approve it when policy allows.
  - PR Steward takes on failing CI checks, merge conflicts and review feedback
  - Claude Approvals signs off routine changes when an organisation's policy permits
  - Beta now for Team and Enterprise plans, GitHub repos only

### Community

- 📰 **[AMD-specific fork of llama.cpp](https://devnull.land/amd-specific-llama-cpp)** — _Hacker News (points)_. — Julian Lam recommends llama-cpp-rdna-boosts, a minimal AMD patch set re-applied to a pinned llama.cpp commit, which took his R9700 eGPU from 35 to 55 tokens/s and prefill from 700 to 1300 tokens/s.
- 📰 **[OpenAI cuts GPT-6.2 usage: Astra hits limits 40% faster, Sol 25% faster](https://twitter.com/thsottiaux/status/2125784147889393806)** — _Hacker News (points)_. — OpenAI's Thibault Sottiaux says a GPT-6.2 billing bug under-charged Astra and Sol usage, so fixing it means limits arrive sooner.
  - You now reach limits 40% faster on Astra and 25% faster on Sol than last week
  - Other models were unaffected and there is no retroactive charge for the difference
  - Go, Plus, Pro and Business subscribers each get one extra saved reset
- 📰 **[AI made self-hosting fun again](https://janlukas.blog/posts/ai-self-hosting)** — _Hacker News (ai/llm/claude)_. — Jan-Lukas Else says agents on Git-tracked Compose and NixOS configs revived his self-hosting; a bootc image took half a day, not a week.
  - Renovate opens update pull requests and a single Git push triggers build and deploy
  - He still insists on understanding every change an agent makes
- 📰 **[PenGPT: A Generative Transformer for Handwriting and Sketches](https://greydanus.github.io/2026/11/12/pengpt/)** — _Hacker News (points)_. — Sam Greydanus trained PenGPT to write in 1,255 learned hands and sketch from text using plain decoders, and credits data work, not architecture, for the result.
  - A 6M-parameter model picks up an unseen writer's hand from a few real words
  - The 54M drawing model shares the same tokenizer; BPE only bought 3.2x shorter sequences
- 📰 **[Google Will Make AI Agents Use Its MCP Servers. The Gmail One Can't Send Email](https://techstackups.com/articles/google-workspace-ai-agents-mcp/)** — _Hacker News (ai/llm/claude)_. — Google made its Workspace MCP servers generally available and will require AI agents to use them from February 2027.
  - The generally available Gmail server cannot send, reply, forward or edit drafts
  - Agents need explicit user confirmation before sending mail, changing sharing or bulk edits
  - REST-to-MCP enforcement begins February 1, 2027, with billing from April 1

- 📧 **[Mind the Trap As LLMs Guess the Data Model: Grain-Aware Guards Against Fan-out in Text-to-SQL (4 minute read)](https://arxiv.org/abs/2611.29009)** — _TLDR · Nov 26_. — An audit testing the fan-out condition on the data finds distorted gold answers for 4.2% of BIRD's dev questions.
  - Grain-aware functional dependencies cut fan-out errors from 18.4% of runs to about 13%
  - Plain functional dependencies helped no more than per-column statistics on the synthetic GrainTraps set
  - Releases BIRD-FanOut, 486 reviewed BIRD questions, plus the synthetic GrainTraps
