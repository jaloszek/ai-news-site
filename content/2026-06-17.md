- 🛠 **[GitHub Copilot CLI for Beginners: Overview of common slash commands](https://github.blog/ai-and-ml/github-copilot/github-copilot-cli-for-beginners-overview-of-common-slash-commands/)** — _GitHub AI blog_. — Covers the slash command interface for GitHub Copilot CLI, explaining how explain, suggest, and setup commands let developers control their terminal AI agent without leaving the command line.

### AI World

- 🟢 **[Predicting model behavior before release by simulating deployment](https://openai.com/index/deployment-simulation)** — _OpenAI blog_. — OpenAI published Deployment Simulation, a method that replays de-identified user conversations through candidate models before release — in a GPT-5-series study it predicted the direction of misbehavior change 92% of the time, compared to 54% for standard evals.
