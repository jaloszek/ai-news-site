# Friday, May 1, 2026

### Claude Code

- 🛠 **[`claude project purge` + gateway model listing — v2.1.126](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)** — Today's release adds `claude project purge [path]`, a new subcommand that wipes all Claude Code project state — transcripts, tasks, file history, and config entry — with `--dry-run`, `-y/--yes`, `-i/--interactive`, and `--all` flags for safe cleanup. The `/model` picker now lists models from your gateway's `/v1/models` endpoint when `ANTHROPIC_BASE_URL` points at a compatible gateway, and `claude auth login` can accept an OAuth code pasted directly into the terminal for WSL2, SSH, and container environments where the browser callback can't reach localhost.
  - `--dangerously-skip-permissions` now bypasses protected-path prompts for `.claude/`, `.git/`, `.vscode/`, and shell config files; auto mode spinner turns red when a permission check stalls; Windows PowerShell 7 is now treated as the primary shell
  - Security: fixed `allowManagedDomainsOnly`/`allowManagedReadPathsOnly` being silently ignored when a higher-priority managed-settings source lacked a `sandbox` block; fixed image paste >2000px crashing the session; fixed Mac sleep "Stream idle timeout"; fixed deferred tools unavailable to subagents on their first turn

- 🔒 **[Claude Security enters public beta](https://siliconangle.com/2026/04/30/anthropic-announces-claude-security-public-beta-find-fix-software-vulnerabilities/)** — Anthropic's codebase vulnerability scanner — powered by Opus 4.7 — is now open to all Claude Enterprise subscribers. It analyzes entire codebases by tracing data flows and interactions between components, provides confidence ratings, exploitation likelihood scores, and generates patches for what it finds. New in beta: scheduled scans, dismissed-finding documentation, and CSV/Markdown export for audit workflows.
  - Originally previewed as "Claude Code Security" in February; hundreds of organizations reportedly found vulnerabilities existing tools had missed for years; integrated into CrowdStrike, Palo Alto Networks, SentinelOne, TrendAI, and Wiz platforms
