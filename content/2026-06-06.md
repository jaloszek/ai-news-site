# Saturday, June 6, 2026

### Claude Code

- 🛠 **[v2.1.166](https://github.com/anthropics/claude-code/releases/tag/v2.1.166)** — _Claude Code releases_. — Adds fallbackModel setting with up to three fallback models tried in order when the primary is overloaded, plus glob pattern support in deny rule tool-name position and hardened cross-session messaging that strips user auth from relayed SendMessage traffic.

### AI World

- 📧 **[NVIDIA releases Nemotron Ultra, the smartest US open-weights model at 400 tokens per second](https://huggingface.co/nvidia/NVIDIA-Nemotron-3-Ultra-550B-A55B-BF16)** — _AlphaSignal_. — Nemotron 3 Ultra is a 550B-parameter MoE model (55B active) scoring top marks on open-weights benchmarks while sustaining 400 tokens per second inference throughput.
- 📧 **[NVIDIA releases Cosmos 3, an open platform for building physical AI models](https://github.com/NVIDIA/cosmos)** — _AlphaSignal_. — NVIDIAs Cosmos 3 ships two open mixtures-of-transformers variants — Nano at 16B params and Super at 64B — unifying vision reasoning, world simulation, and robot action generation in a single download, with early deployments at Agile Robots and Linker Vision already using its action-conditioned trajectory output.
- 🟡 **[Thousand Token Wood: shipping a multi-agent economy on a 3B model](https://huggingface.co/blog/build-small-hackathon/thousand-token-wood-sim)** — _Hugging Face blog_. — A Hugging Face hackathon project demonstrates a multi-agent economic simulation running entirely on a 3B parameter model, proving that complex agent interactions work on small local models.
- 📧 **[Google releases open 2.4B model for real-time on-device music generation](https://huggingface.co/google/magenta-realtime-2)** — _AlphaSignal_. — Googles 2.4B parameter Magenta Realtime model runs music generation locally on device with no cloud dependency, optimized for low-latency interactive sessions.
- 🟡 **[Designing the hf CLI as an agent-optimized way to work with the Hub](https://huggingface.co/blog/hf-cli-for-agents)** — _Hugging Face blog_. — Hugging Face shipped hf v1.9.0 with an agent mode that auto-detects Claude Code and Codex environments, cuts token consumption by 6x versus the Python SDK, and raised task success rates by 10pp — the redesign was driven by Claude Code alone generating 49 million requests to the Hub since April.
