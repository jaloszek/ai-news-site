### Claude Code

- 🛠 **[v2.1.172](https://github.com/anthropics/claude-code/releases/tag/v2.1.172)** — _Claude Code releases_. — Sub-agents can now recursively spawn their own sub-agents up to 5 levels deep. Amazon Bedrock region resolution follows AWS SDK precedence from ~/.aws config, and sessions using 1M context without credits no longer get permanently stuck.
- 🛠 **[Give GitHub Copilot CLI real code intelligence with language servers](https://github.blog/ai-and-ml/github-copilot/give-github-copilot-cli-real-code-intelligence-with-language-servers/)** — _GitHub AI blog_. — LSP integration gives Copilot CLI real-time type checking and symbol resolution instead of brute-force text search. The setup works with any language server through a simple configuration file.
