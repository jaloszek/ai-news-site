### Coding Agents

- 🛠 **[v2.1.275](https://github.com/anthropics/claude-code/releases/tag/v2.1.275)** — _Claude Code releases_. — v2.1.275 adds a send-now key (ctrl+enter, or ctrl+x ctrl+s) that interrupts the current turn and sends all queued messages at once, syncs the skills and plugins enabled on your claude.ai account into terminal sessions (opt out with syncClaudeAiSkills: false), and warns at startup when a configured otelHeadersHelper fails.
- 🛠 **[0.155.0](https://github.com/openai/codex/releases/tag/rust-v0.155.0)** — _Codex releases_. — Codex 0.155.0 adds experimental /voice conversations with live transcripts and microphone controls (enabled through /experimental), live reasoning summaries in the TUI status row, task hiding, archiving and deletion in the agents overview, and Touch ID verification for MCP requests on supported Macs.

### AI World

- 📰 **[Anthropic keeps pushing Claude Code toward autonomous coding with new parallel agent workflows](https://the-decoder.com/anthropic-keeps-pushing-claude-code-toward-autonomous-coding-with-new-parallel-agent-workflows/)** — _The Decoder_. — Anthropic rebuilt Claude Code's Projects feature so a coordinator agent splits a goal across parallel cloud threads, each a full session on its own branch and repo copy that can open pull requests and run tests while sharing one memory. The beta is limited to select Pro and Max subscribers, with Team and Enterprise later and local execution coming soon.
- 📰 **[AI agent swarms are a massive waste of tokens with zero quality gain, says OpenAI Codex developer](https://the-decoder.com/ai-agent-swarms-are-a-massive-waste-of-tokens-with-zero-quality-gain-says-openai-codex-developer/)** — _The Decoder_. — An OpenAI Codex developer, Eric Provencher, argues that beyond two parallel sub-agents the extra tokens buy no quality because the agents re-check each other's work — a coordination tax. He pointed to a 1,393-agent run that spent $20,000 refactoring a single Python file, saying one Astra agent could have done it for a fraction of the cost.
- 🟢 **[Introducing Astra for Law](https://openai.com/index/astra-for-law)** — _OpenAI blog_. — OpenAI did not ship a new model — it wrapped GPT-6 Astra in a legal search index covering more than 230 million URLs of U.S. case law, statutes and regulations. On Vals AI’s Legal Research Bench it answered 54% of 200 questions correctly, versus 38.7% for plain GPT-6 Astra with web search alone.
- 🟢 **[Reimagining advertising with AI](https://openai.com/index/reimagining-advertising-with-ai)** — _OpenAI blog_. — OpenAI previews AI-powered advertising experiences including Sponsored Agents, tools for marketers, and integrations with HubSpot and Shopify.
- 🔵 **[Making global data easier to explore](https://blog.google/innovation-and-ai/technology/ai/google-un-data-commons-platform/)** — _Google AI blog_. — Google and the UN system turned decades of scattered global statistics into one searchable, machine-readable graph — the UN System Data Commons, built on Google’s existing Data Commons platform. You can ask it questions in plain language, AI agents can pull verified figures directly, and the UN aims to fold in 80% of its statistical datasets by 2027.

### YouTube

- 🎥 [What AI Researchers Saw, Before Their Demand to ‘Pace’ AI](https://www.youtube.com/watch?v=J3ljHm57yU0) — **AI Explained** (24m53s). — AI Explained walks through the six axes researchers are citing behind the loudest calls yet to pace frontier AI, plus the incidence reports and trends feeding those warnings, anchored to primary documents like Dario Amodei's 'We Must Pace the Frontier', Anthropic's September 2026 threat-intelligence report, and Jacob Coxon's resignation. Useful if the past two weeks of safety headlines read louder than the actual evidence.

- 🎥 [open-code-review vs. General-Purpose Agents: Catch Bugs Precisely with 90% Fewer Tokens](https://www.youtube.com/watch?v=kIzblt7VLDE) — **DevCovery** (6m24s). — For teams weighing an AI reviewer against a general-purpose coding agent, Alibaba's open-source open-code-review splits the work: deterministic engineering handles file selection, related-file bundling and rule matching, while LLM agents only do dynamic context retrieval and line-level comments. It ships built-in multilingual rules for NPE, thread-safety, XSS and SQL injection, and supports OpenAI and Anthropic models. The README claims higher precision and F1 than Claude Code on the same underlying model at roughly 1/9 the tokens; the accompanying paper reports 5-15x fewer tokens and up to 2.17x higher SEM-F1 on AACR-Bench, trading some recall for lower noise.

  <p align="center"><a href="https://youtube.com/watch?v=kIzblt7VLDE"><img src="https://img.youtube.com/vi/kIzblt7VLDE/mqdefault.jpg" alt="thumb"></a></p>
- 🎥 [Did Google just kickstart the intelligence explosion?](https://youtube.com/watch?v=LoLYw--s-5w) — **Fireship** (4m59s). — Google DeepMind's Dream-RSI turns an agent's past discovery logs into a replay simulator: instead of re-running costly online searches, the agent "dreams" thousands of candidate exploration policies against the recorded discovery tree and only the winner is deployed. Fireship's question is whether that is genuine recursive self-improvement or just a search algorithm with caching. The paper reports 1.7x fewer discovery-agent calls than fixed exploration and up to 162x fewer than SimpleTES across algorithm engineering, math optimization and GPU-kernel tasks.
