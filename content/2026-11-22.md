### Coding Agents

- 🛠 **[1.0.115-2](https://github.com/github/copilot-cli/releases/tag/v1.0.115-2)** — _Copilot CLI releases_. — Enables Windows sandbox package queries by default and adds custom provider models.
  - Set `sandbox.userPolicy.capabilities` to `[]` to opt out of those queries
  - Ctrl+X then A in `/model` adds and switches custom provider models in local sessions
  - Gemini 4 Hydrogen joins the picker with Extra High reasoning when your account has it
  - GPT-6.2 Astra support is added, and MAI-Code-2-Flash appears under New models
- 🛠 **[v4.1.27](https://github.com/cline/cline/releases/tag/v4.1.27)** — _Cline releases_. — Cline can now reach LM Studio servers that require authentication, and MCP tools get a read-only badge.
  - LM Studio settings gain an API key field for Require Authentication servers
  - The MCP tab badges tools whose server declares them read-only
  - New installs start on the first free model instead of Claude Sonnet 5.5
  - read_files now returns up to 2000 lines or about 48k characters
- 🛠 **[v1.43.0](https://github.com/OpenHands/OpenHands/releases/tag/v1.43.0)** — _OpenHands releases_. — Adds automations from the setup wizard and a Features page for experimental flags.
  - Experimental decision cards render in chat, as do the agent's message edits
  - Conversation reactions get their own entry on that Features page for opt-in
  - The conversation message list is now virtualized for performance
  - Automation run rows show a conversation indicator icon

### AI World

- 📰 **[Frostbite: A new CPU architecture discovered, designed and verified by AI](https://architectlabs.com/blog/frostbite)** — _Hacker News (points)_. — Architect Labs says its AI agents took a new CPU from instruction set to final layout, claiming 4.59x better performance-per-watt.
  - Beats a modern dual-issue in-order core across 25 workloads, 15 held out
  - Claims 8.77x performance-per-area, on pre-silicon simulations only
  - Synthesized on a 7nm process: 800 MHz at synthesis, 500 MHz in the final GDS
- 📰 **[New open model Inkling 2 Mini thinks in loops to solve problems with fewer words and still runs on a laptop](https://the-decoder.com/new-open-model-inkling-2-mini-thinks-in-loops-to-solve-problems-with-fewer-words-and-still-runs-on-a-laptop/)** — _The Decoder_. — Thinking Machines' Inkling 2 Mini reruns its middle 12 layers three times per token, so it thinks longer without writing more.
  - 26.4B total parameters, 3.4B active, roughly a 20GB footprint
  - Small enough for any Mac with 32GB of RAM via Ollama
  - Matches Qwen3.8-27B's 20.1 on the AA Index
  - Leads sub-100B open models on DeepSWE v1.1 at 48.2%
- 📰 **[Bytedance argues most AI training phases are unnecessary and backs it up with a competitive open model](https://the-decoder.com/bytedance-argues-most-ai-training-phases-are-unnecessary-and-backs-it-up-with-a-competitive-open-model/)** — _The Decoder_. — ByteDance and US universities argue three training phases suffice; their open Axion 1.0 agent scores near OpenAI and Anthropic.
  - Model weights, training data and code all released
  - Their case: curated data beats stacking ever more training rounds
  - Paper says nested pipelines make it near-impossible to tell what helps
- 🟡 **[Tencent Hy4 is live on Together AI](https://www.together.ai/blog/tencent-hy4)** — _Together AI blog_. — Tencent's flagship open model picked up vision and a US serverless home, at $0.83 per million input tokens.
  - Hy4 is a 770B-parameter mixture-of-experts with 49B active per token
  - First in the Hy family to take images, plus tool calling and JSON output
  - 1M-token context window, served as `tencent/Hy4`
- 🟡 **[Security event: Prompt leakage for requests in June and July of 2026](https://www.together.ai/blog/security-event-prompt-leakage-for-requests-in-june-and-july-of-2026)** — _Together AI blog_. — An AI coding agent leaked the credential to Together's private prompt store, and someone downloaded the samples before the commit was reverted.
  - Samples came from MiniMax M3, GLM-5.2 and Kimi K2.6 requests
  - Dated mainly June 24, July 4, July 8 and July 14, 2026
  - The downloader then hunted the prompts for other services' credentials
  - Together now makes zero data retention the default for new accounts
