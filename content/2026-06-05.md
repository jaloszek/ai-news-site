# Friday, June 5, 2026

### Claude Code

- 🛠 **[v2.1.163](https://github.com/anthropics/claude-code/releases/tag/v2.1.163)** — _Claude Code releases_. — Claude Code v2.1.163 adds requiredMinimumVersion and requiredMaximumVersion managed settings to enforce version ranges, introduces /plugin list with --enabled/--disabled filters, and adds a c clipboard shortcut to /btw.

### AI World

- 🟡 **[EVA-Bench Data 2.0: 3 Domains, 121 Tools, 213 Scenarios](https://huggingface.co/blog/ServiceNow-AI/eva-bench-data)** — _Hugging Face blog_. — ServiceNow expands EVA-Bench to 213 scenarios across 3 domains with 121 tools, providing a standardized evaluation for enterprise virtual agents on tool-use tasks.
- 🟡 **[Nemotron 3.5 Content Safety: Customizable Multimodal Safety for Global Enterprise AI](https://huggingface.co/blog/nvidia/nemotron-3-5-content-safety)** — _Hugging Face blog_. — NVIDIA releases Nemotron 3.5 Content Safety, a customizable multimodal safety model that lets enterprises define their own content policies across text and image inputs.
- 🟢 **[Dreaming: Better memory for a more helpful ChatGPT](https://openai.com/index/chatgpt-memory-dreaming)** — _OpenAI blog_. — OpenAI's Dreaming V3 replaces ChatGPT's old saved-memories list with a background system that synthesizes preferences across conversations — factual recall jumped from 67.9% to 82.8%, and a 5x compute cut makes the feature practical for free-tier users for the first time.
- 🟢 **[How Endava is redesigning software delivery around AI agents](https://openai.com/index/endava-frontiers)** — _OpenAI blog_. — Endava retooled its 11,000-person delivery model around OpenAI's Codex and ChatGPT Enterprise — building an AI-native methodology called DavaFlow that collapsed requirements analysis from weeks to hours and pushed agentic workflows into legal, finance, and operations teams alongside engineering.

**Reddit — Local AI**

**Reddit — AI World**

- 📝 **[Co-Existence and the End of Co-Intelligence](https://www.oneusefulthing.org/p/co-existence-and-the-end-of-co-intelligence)** — _One Useful Thing (Ethan Mollick)_. — Ethan Mollick argues that as AI capabilities grow, the framing of humans co-intelligently working with AI gives way to autonomous AI agents that require a fundamentally different relationship model.

- 📧 **[New robot planner runs 19x faster and cuts jerky movement by 38%](https://arxiv.org/abs/2603.13733)** — _AlphaSignal_. — A new motion planning algorithm on arXiv achieves 19x faster planning and 38% reduction in jerk over prior methods, making smooth real-time robotic movement feasible on cheaper hardware.
