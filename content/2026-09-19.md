### Coding Agents

- 🛠 **[v2.1.277](https://github.com/anthropics/claude-code/releases/tag/v2.1.277)** — _Claude Code releases_. — Claude Code v2.1.277 adds AGENTS.md support — a project with no CLAUDE.md now reads AGENTS.md instead, switchable under Project instructions in /config (not yet on Bedrock, Vertex or Foundry) — plus CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1, which makes an egress-bound gateway hand the proxy the hostname instead of resolving it locally.

### AI World

- 📰 **[Security researchers used Anthropic's Claude to hack OpenAI's internal systems in under 72 hours](https://the-decoder.com/security-researchers-used-anthropics-claude-to-hack-openais-internal-systems-in-under-72-hours/)** — _The Decoder_. — Three Hacktron AI researchers turned a year-old libheif image bug plus a misconfigured OpenAI single sign-on into a full breach — employee ChatGPT and Codex accounts, then the internal monorepo — all in under 72 hours, and only once Claude Opus 5 shipped; the previous model had failed with ASLR enabled. OpenAI paid a $6,500 bounty.
- 📰 **[Anthropic wants you to know Claude leads a quarter of its research, but "lead" doesn't mean what you think](https://the-decoder.com/anthropic-wants-you-to-know-claude-leads-a-quarter-of-its-research-but-lead-doesnt-mean-what-you-think/)** — _The Decoder_. — Anthropic says Claude now leads 26 percent of its model-development work, up from under one percent in February, but that number comes from Claude scoring itself against Epoch AI's AL0-AL5 scale, where "leads" (AL4) still means a human reads the report and decides what ships. The model's scores matched human raters just 59 percent of the time.
- 🟡 **[How a global fintech scaled coding agent traffic with Dedicated Model Inference](https://www.together.ai/blog/global-fintech-scales-coding-agent-traffic-with-dedicated-model-inference)** — _Together AI blog_. — Together's Dedicated Model Inference let a global fintech move its coding assistant onto self-serve endpoints — running GLM 5.2 at 256K context across 56 B200s — so its own engineers could scale capacity, roll out models, and blue/green test without filing tickets to Together. The traffic is peak-load and low-TPS, concentrated in engineering hours.
- 🟢 **[How Cooley is accelerating IPO work with ChatGPT](https://openai.com/index/cooley-gopublic)** — _OpenAI blog_. — Cooley built GO Public with OpenAI as a design partner, putting IPO prep on ChatGPT Work: an agentic harness drafts a tailored Form S-1 in minutes rather than days, leaving lawyers the strategic calls. The firm advised on 180 deals worth $51.5 billion in 2025.
- 🔵 **[New experts join Google’s AI & Economy team](https://blog.google/innovation-and-ai/technology/ai/expanding-ai-economy-research-bench/)** — _Google AI blog_. — Google expanded its AI & Economy Research Program: 2025 Nobel laureate Philippe Aghion joins as an academic advisor and Ajay Agrawal of Toronto's Rotman School as a visiting fellow, alongside existing names Michael Spence and David Autor. Ex-McKinsey Global Institute partner Anu Madgavkar and Wharton's Daniel Rock come in as directors.

### YouTube

- 🎥 [SoL-Pi: Token-Efficient Coding Agent Harness](https://www.youtube.com/watch?v=66VMcm_014I) — **AI Research Roundup** (4m21s). — NVIDIA's SoL-Pi packs four reusable efficiency mechanisms into an extension for the Pi coding agent, holding roughly 94% of Pi's EdgeBench score on 51 tasks while cutting token traffic 44.7-49.0% and API cost by about a third — roughly $8.75-$13.50 saved per hour versus native Codex and Claude Code. For anyone whose long agent runs bill by the token.

- 🎥 [Jev (Fully Tested) + Browser Use: FASTEST AI Agent I'VE TRIED YET!](https://youtube.com/watch?v=SNJ3yuJ_QwY) — **AICodeKing** (8m22s). — TypeSafe's Jev is a structured-decision model, not a chatbot: on support routing, negation detection, urgency scoring, exact-value selection and agent auditing it returned millisecond-scale results on very cheap input tokens, and it resisted a basic prompt injection. The catches are that restricted outputs do not guarantee a correct answer when the candidate list is incomplete, and it still needs broader testing before production.

(Here's How to Evolve It)](https://youtube.com/watch?v=mjQlZrteMIY) — **Cole Medin** (16m06s). — The follow-up for anyone whose personal AI second brain has outgrown solo use: chat, repo and doc data land in one table, every row gets a label, and the database enforces those labels on every read so a coding agent can query it over MCP with its own token — demoed on Oracle AI Database but built to run on the stack you already have.
