# Wednesday, June 10, 2026

### Claude Code

- 🛠 **[v2.1.170](https://github.com/anthropics/claude-code/releases/tag/v2.1.170)** — _Claude Code releases_. — v2.1.170 ships Claude Fable 5, a Mythos-class model Anthropic considers safe for general use, and fixes session transcript persistence when launched from VS Code integrated terminals.
- 🛠 **[From one-off prompts to workflows: How to use custom agents in GitHub Copilot CLI](https://github.blog/ai-and-ml/github-copilot/from-one-off-prompts-to-workflows-how-to-use-custom-agents-in-github-copilot-cli/)** — _GitHub AI blog_. — Custom agents in GitHub Copilot CLI turn one-off terminal prompts into repeatable, reviewable workflows by encoding team-specific stack knowledge and conventions.

### AI World

- 🟡 **[Introducing North Mini Code: Cohere’s First Model For Developers](https://huggingface.co/blog/CohereLabs/introducing-north-mini-code)** — _Hugging Face blog_. — At 30B total parameters with only 3B active per token, Cohere’s MoE coding model runs on a single H100 and scores 33.4 on the Artificial Analysis Coding Index — ahead of Qwen3.5 and Gemma 4 in the same size class, though independent testing found it generates three times the output tokens of comparable models.
- 🟢 **[How engineers at Nextdoor use Codex to build without limits](https://openai.com/index/nextdoor)** — _OpenAI blog_. — Nextdoor engineers use OpenAI Codex with GPT-5.5 to investigate hard-to-reproduce issues and build across platforms, letting small teams focus on product outcomes.
- 🟡 **[Can Voice Agents Handle Bilingual Customers? Benchmarking Frontier ASR on Code-Switched Speech](https://huggingface.co/blog/ServiceNow-AI/code-switching)** — _Hugging Face blog_. — ServiceNow tests frontier ASR models on code-switched speech, benchmarking how well voice agents handle bilingual customers who switch languages mid-conversation.
- 🟢 **[What Codex unlocks for Notion](https://openai.com/index/notion)** — _OpenAI blog_. — Notion uses Codex to one-shot product specs and build AI Voice Input for the web, multiplying engineering output across small teams without adding headcount.
