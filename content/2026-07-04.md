# Saturday, July 4, 2026

### Coding Agents

- 🛠 **[v2.1.200](https://github.com/anthropics/claude-code/releases/tag/v2.1.200)** — _Claude Code releases_. — AskUserQuestion dialogs no longer auto-continue by default and the default permission mode is now Manual. Also fixes a startup crash from invalid MCP config values and background sessions dropping after sleep or wake.
- 🛠 **[v2.1.201](https://github.com/anthropics/claude-code/releases/tag/v2.1.201)** — _Claude Code releases_. — Drops the mid-conversation system role that previously injected harness reminders into Claude Sonnet 5 sessions, reducing prompt overhead for long-running agent tasks.
- 🛠 **[CLI v3.0.35](https://github.com/cline/cline/releases/tag/cli-v3.0.35)** — _Cline releases_. — ClinePass is now enabled for all CLI users, Tencent TokenHub joins the provider list (from SDK v0.0.55), and first-prompt truncation on high-output models like MiniMax M3 is fixed so initial tasks no longer get auto-compacted and lost.
- 🛠 **[CLI v3.0.36](https://github.com/cline/cline/releases/tag/cli-v3.0.36)** — _Cline releases_. — Fixes plan mode's switch_to_act_mode to end the plan-mode run immediately and continue with the approved plan using full act-mode tools, instead of waiting for the end of the turn. Also prevents Tab mode from auto-starting unapproved plan execution.
- 🛠 **[v7.4.1 (release)](https://github.com/Kilo-Org/kilocode/releases/tag/v7.4.1)** — _Kilo Code releases_. — Adds bidirectional text support in the prompt input, fixes missing kilo-sandbox-mutation-worker.js that caused sandboxed file operations to fail with Module not found, and fixes the reasoning-variant picker in the New Worktree dialog where a portal popover was swallowed by the modal overlay.

### AI World

- 📰 **[Microsoft follows Anthropic and OpenAI into the AI super app race with overhauled Copilot and AutoPilot agents](https://the-decoder.com/microsoft-follows-anthropic-and-openai-into-the-ai-super-app-race-with-overhauled-copilot-and-autopilot-agents/)** — _The Decoder_. — Microsoft plans to merge consumer and enterprise Copilot into a single app in August, cutting features like Copilot Podcasts and introducing paid AutoPilot agents that handle background tasks for an extra fee.
- 📰 **[Claude Code's complicated China problem involves bans on both sides of the Pacific](https://the-decoder.com/claude-codes-complicated-china-problem-involves-bans-on-both-sides-of-the-pacific/)** — _The Decoder_. — Anthropic is blocking Chinese companies like ByteDance from accessing Claude Code, but they bypass restrictions through VPNs and overseas subsidiaries, while Alibaba has banned internal use after finding hidden code that identifies Chinese users.

### Community

**Reddit — AI World**

- 📝 **[Skill engineering and the case against one-shot AI design](https://www.latent.space/p/skill-engineering-design)** — _Latent Space (swyx)_. — Latent Space interviews Paul Bakaus (Impeccable) on skill engineering as the discipline where agents are given a design vocabulary like 'bolder' or 'quieter' but humans stay in the loop — 'there is no auto, and there will be no auto.'

- 🧪 **[TokenScope: Token-Level Explainability and Interpretability for Code-Oriented Tasks in Large Language Models](https://arxiv.org/abs/2607.01235)** — _arXiv cs.CL_. — TokenScope, from Amirreza Esmaeili and Fatemeh Fard, is an interactive tool that exposes token-level uncertainty and lets developers explore alternative decoding paths during LLM code generation, with counterfactual branching and AST-aware aggregation.
