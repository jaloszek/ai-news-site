# Tuesday, July 7, 2026

### Coding Agents

- 🛠 **[v2.1.202](https://github.com/anthropics/claude-code/releases/tag/v2.1.202)** — _Claude Code releases_. — A "Dynamic workflow size" setting in /config caps agent count at small, medium, or large as an advisory guideline, and workflow-spawned agents now emit workflow.run_id and workflow.name OTel attributes.
- 🛠 **[v1.17.14](https://github.com/anomalyco/opencode/releases/tag/v1.17.14)** — _OpenCode releases_. — Code mode adds an MCP adapter for confined orchestration scripts and hides the execute tool when disabled, with fixes for paginated MCP tool-catalog metadata loss and Copilot model routing.
- 🛠 **[jetbrains/v7.0.1: feat(cli): opt-in project memory (#11921)](https://github.com/Kilo-Org/kilocode/releases/tag/jetbrains%2Fv7.0.1)** — _Kilo Code releases_. — Opt-in project memory in v7.0.1 adds turn-close consolidation with secret redaction, kilo_memory_save / kilo_memory_recall tools, and a /memory TUI sidebar -- memory is disabled by default and enabled via /memory on.
- 🛠 **[1.9.0](https://github.com/OpenHands/OpenHands/releases/tag/1.9.0)** — _OpenHands releases_. — OpenHands 1.9.0 routes unclaimed automation events to the default org on single-org installs, adds a hide_personal_workspaces flag for org-only deployments, and exposes a switch_acp_model proxy endpoint for cloud conversations.
