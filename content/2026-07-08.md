# Wednesday, July 8, 2026

### Coding Agents

- 🛠 **[v2.1.203](https://github.com/anthropics/claude-code/releases/tag/v2.1.203)** — _Claude Code releases_. — Warns before login expiry so background sessions aren't interrupted, fixes the 15–20 s macOS stall on opening background agents (regression in 2.1.196), and recovers sessions whose daemon token goes stale instead of leaving them permanently unresponsive. Binary size drops ~7 MB from lazy-loaded dependencies.
- 🛠 **[v2.1.204](https://github.com/anthropics/claude-code/releases/tag/v2.1.204)** — _Claude Code releases_. — Fixes hook events not streaming during SessionStart hooks in headless sessions, which could cause remote workers to be idle-reaped mid-hook.
- 🛠 **[v1.17.15](https://github.com/anomalyco/opencode/releases/tag/v1.17.15)** — _OpenCode releases_. — Z.ai context-window overflows now surface the correct failure mode instead of a generic error, and model-details tooltips are restored in the model picker.
- 🛠 **[Hermes Agent v0.18.1 (2026.7.7)](https://github.com/NousResearch/hermes-agent/releases/tag/v2026.7.7)** — _Hermes Agent releases_. — Rolls up ~667 commits across ~990 files (+89.5k/−10.4k lines) since v0.18.0, including Windows installer self-healing, WhatsApp dashboard pairing, and MCP/provider fixes.

### AI World

- 📰 **[Copilot goes cheap as Microsoft phases out OpenAI and Anthropic models to cut costs](https://the-decoder.com/copilot-goes-cheap-as-microsoft-phases-out-openai-and-anthropic-models-to-cut-costs/)** — _The Decoder_. — Microsoft's MAI models are handling tens of thousands of weekly Copilot requests in Excel and Outlook, replacing OpenAI and Anthropic. Mustafa Suleyman said Microsoft aims to reduce and ultimately eliminate Anthropic spend, with cheaper MAI defaults and third-party models as potential paid add-ons.
- 🔵 **[Expanding Managed Agents in Gemini API:  background tasks, remote MCP and more](https://blog.google/innovation-and-ai/technology/developers-tools/expanding-managed-agents-gemini-api/)** — _Google AI blog_. — Google's Managed Agents in the Gemini API add background execution with a polling ID for async workflows and direct remote MCP server connections — turning them from a synchronous sandbox into something closer to a worker agent.
- 📰 **[Mistral CEO Mensch says proprietary AI models give labs a front-row seat to your business processes](https://the-decoder.com/mistral-ceo-mensch-says-proprietary-ai-models-give-labs-a-front-row-seat-to-your-business-processes/)** — _The Decoder_. — Mistral CEO Arthur Mensch warns that proprietary AI models give their makers a window into customer business processes — labs that have a track record of going after their most successful customers thanks to this information. He argues for open models alongside Palantir CEO Alex Karp, who posted a similar call for AI sovereignty days earlier.
- 🟡 **[Run AI workloads on any cloud, store on Hugging Face: zero-egress storage with SkyPilot](https://huggingface.co/blog/skypilot-hf-storage)** — _Hugging Face blog_. — Hugging Face Storage is now a first-class SkyPilot backend — mount any Hub repo or bucket with a single hf:// URL and run compute on any of 20+ cloud providers with zero egress on reads. At $12-18/TB/month versus S3's $23/TB plus egress, it removes the cost penalty that usually pins AI workloads to wherever the data lives.
- 🟡 **[From Hugging Face to Amazon SageMaker Studio in one click](https://huggingface.co/blog/amazon/one-click-to-sagemaker-studio)** — _Hugging Face blog_. — Hugging Face models now deep-link into Amazon SageMaker Studio — one click lands on a pre-configured fine-tuning or deployment page with IAM permissions already set and GPU quota shown in the instance picker, skipping the usual multi-step AWS Console setup.
