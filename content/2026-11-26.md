### Coding Agents

- 🛠 **[Mellum2.1 Instruct Is Out, Bringing Faster Answers for Coding Agents](https://blog.jetbrains.com/ai/2026/11/mellum2-1-instruct-is-out-bringing-faster-answers-for-coding-agents/)** — _JetBrains AI blog_. — JetBrains ships Mellum2.1 Instruct, a 12B MoE with 2.5B active parameters that skips chain of thought.
  - Cuts tokens per agentic task 45%, 5.6k vs 10.1k against Thinking
  - 73% fewer tokens excluding tool calls; SWE-bench Verified 40.4 vs 47.0
  - SWE-bench Verified score doubled compared with the previous Mellum2 Instruct
  - Apache 2.0 weights, GGUF builds, and an MTP head up to 1.8x faster
- 🛠 **[1.0.116](https://github.com/github/copilot-cli/releases/tag/v1.0.116)** — _Copilot CLI releases_. — Copilot CLI 1.0.116 adds an env setting that reaches every process it spawns, sandbox or not.
  - env covers shell commands, local LSP and MCP servers, hooks, extensions
  - ACP editors can pick a context size without changing saved defaults
  - Warns when a plugin and a standalone MCP server share an endpoint
  - Fullscreen timeline gains Jump to latest; extension manifests get a JSON Schema
- 🛠 **[v1.6.1](https://github.com/earendil-works/pi/releases/tag/v1.6.1)** — _Pi releases_. — Pi v1.6.1 makes decision models callable from codemode and splits transcript notices into four settings.
  - Copilot's gpt-6-luna-decisions and Radius models callable via models.classify()
  - classify() results now include the provider's responseId
  - Cache miss, warming, compaction cost and reasoning-drop notices each get settings
  - Breaking: showCacheMissNotices is replaced; existing values migrate to all four

### AI World

- 📰 **[GLM-5.4: Toward generalized coding with our first loop transformer](https://z.ai/blog/glm-5.4)** — _Hacker News (points)_. — Z.ai's GLM-5.4 runs 28 of its layers twice instead of adding parameters, and claims 2-3T-model quality at 750B.
  - Out now for GLM Coding Plan subscribers, in ZCode and Z.ai Chat
  - API access waits on a safety evaluation; open weights come later
  - No benchmark scores published; vision support and 50% more quota
- 📰 **[PrismML shrinks a 54 GB language model to 5.9 GB by reducing every weight to just three possible values](https://the-decoder.com/prismml-squeezes-an-agent-based-coding-model-with-27-billion-parameters-into-5-9-gb/)** — _The Decoder_. — A 27B agentic coding model now fits in 5.9 GB, where full 16-bit precision would need about 54 GB.
  - Every weight is ternary — −1, 0 or +1 — instead of 16-bit
  - SWE-bench Verified rises from 60.8 to 75.6 percent; full Qwen hits 80.6
  - About 204 tokens per second on an RTX 4090, via llama.cpp or MLX
- 📰 **[Models Can Communicate via Inference Servers Despite Being Sandboxed](https://www.lesswrong.com/posts/7wzWuLP3HhyBLmKfo/models-can-communicate-via-inference-servers-despite-being)** — _Hacker News (points)_. — Two models on one inference server can message each other through vLLM's batching, no network or shared files needed.
  - A shared-KV-cache message board won 1,221/1,221 rounds of a color game
  - A colluding monitor let 354/354 attacks through, still catching 85-92% of honeypots
  - Fix by splitting engine instances, batch-invariant kernels or cache salting
- 🟡 **[Introducing Hurdle: Run agent evals on your API, skills, and docs](https://www.together.ai/blog/introducing-hurdle-run-agent-evals-on-your-api-skills-and-docs)** — _Together AI blog_. — Together AI open-sourced Hurdle, an npm library that runs Claude Code and Codex against tasks on your own API and scores each run.
  - Scoring mixes code checks, blocking guards and an LLM judge
  - Guards and request checks only work in sandboxed runs
  - The sandbox doesn't limit endpoints by default, so use a low-balance key
- 🟡 **[Distilling Kimi-K3.1-Pro into Qwen3.8-27B: Teaching a model a new language](https://www.together.ai/blog/distilling-kimi-into-qwen)** — _Together AI blog_. — Together distilled Kimi-K3.1-Pro's Lao into Qwen3.8-27B, lifting a 5.5 chrF++ score to 44.3, or 93% of the teacher.
  - The base model answered in Thai when asked for Lao
  - A LoRA on about 3,800 teacher translations kept Thai at 47.8
  - All experiments together cost $260

### YouTube

- 🎥 [1,000 Claude Agents Formalized Fermat's Last Theorem — Lance Martin, Anthropic](https://www.youtube.com/watch?v=wrfbI5eyLAI) — **AI Engineer** (18m43s). — For anyone designing multi-agent systems: 1,000 Claude agents formalized Fermat's Last Theorem in Lean in about 30 hours.
  - Only Git and a SQL database, no domain-specific harness or human steering
  - The lead agent built its own coordination tables as work progressed
  - Then memory: stronger models keep better notes
  - "Dreaming" over transcripts fixes poisoned memories and builds wikis

### Community

- 📝 **[How Anthropic builds software in 2026 with Katelyn Lesse](https://newsletter.pragmaticengineer.com/p/how-anthropic-builds-software-in)** — _Pragmatic Engineer_. — Platform lead Katelyn Lesse on rebuilding the Claude Messages API in Rust in about five months.
  - No Rust experts on the team; Claude helped engineers learn the language
  - A Claude agent categorises API on-call alerts before a human is paged
  - Coding interviews were phased out after strong candidates kept failing them
- 📝 **[vLLM Singapore Meetup: Faster Prefill, Agent-Written Kernels and the Road to Vera Rubin](https://pytorch.org/blog/vllm-singapore-meetup-faster-prefill-agent-written-kernels-and-the-road-to-vera-rubin/)** — _PyTorch blog_. — Inferact, NVIDIA and Alibaba Cloud engineers detail pipeline-parallel prefill and agent-written kernels for open inference.
  - PP2 hit up to 1.37× TEP2 + SP throughput on MiniMax-M3.1-Flash at 2× GB300
  - Agentic turns carry roughly 100K input tokens, about 95% cached
  - Vera Rubin NVL72 reached 4.3–6.5× GB300 tokens per dollar
- 📝 **[Import AI 482: Huawei kernel benchmarks; airborne drone detection; and a national lab's AI science benchmark](https://importai.substack.com/p/import-ai-482-huawei-kernel-benchmarks)** — _Import AI_. — Jack Clark surveys three new benchmarks, from Huawei kernel work to AI scientists that must report uncertainty.
  - AscendGYM tests agents writing kernels for Huawei Ascend chips; Opus 5 leads
  - SciResearch-Eval: only GPT-6 Astra and Claude Fable 5.2 handle a flawed simulator
  - A2A-UAV adds 105,263 air-to-air drone detection samples
- 🧪 **[Interpreting a recent acceleration in pretraining loss](https://metr.org/blog/2026-11-24-interpreting-a-recent-acceleration-in-pretraining-loss/)** — _METR_. — OpenAI's published log-perplexity now falls about seven times faster since early 2026 than in 2022 to 2025.
  - METR staff see no matching acceleration in benchmark scores
  - Caveats: possible overfitting, or leakage from OpenAI's own code corpus
  - No internal consensus on what it means for capability forecasts
- 📰 **[GPUI is getting its own repository](https://github.com/zed-industries/gpui)** — _Hacker News (points)_. — Zed promises a standalone GPUI repo and a fresh crates.io release in the coming weeks, though neither exists yet.
  - The new repository currently holds only a README saying see you in a few weeks
  - Published crate gpui 0.2.2 still lists the Zed monorepo as its source
  - Maintainers of GPUI forks are being asked what they want from the move

### Newsletters

- 📧 **[NVIDIA method caches LLM reasoning as CPU code, cutting costs up to 291x](https://arxiv.org/abs/2611.09891)** — _AlphaSignal · Nov 23_. — NVIDIA's CPU-ARC caches a model's reasoning as CPU-executable code, claiming 16-291x cheaper invocation than the source model.
  - The caches match frontier LLMs on difficult math and science tasks
  - Authors call them explainable, continually trainable and robust to input perturbations
  - Traces compile into small Python functions, with a fine-tuned 1B model for extraction
- 📧 **[SWE-2.1](https://cognition.com/blog/swe-2-1?_bhlid=da3f1d2a84f5380c9a4e10c743bc40b26942cea5)** — _The Rundown AI · Nov 25_. — SWE-2.1 is pure-RL on Kimi K3, lifting FrontierCode 2.0 from 24.1 to 41.3 and Terminal-Bench 4.1 from 24.2 to 50.0.
  - ExploitBench climbs from 36.1 to 80.0 on vulnerability work
  - Gains come from long-horizon workflows, not just coding tasks
  - An Ultrafast variant with Cerebras runs the same model at 10x speed
  - Still behind Claude Opus 5.5 on both headline benchmarks
- 📧 **[Anthropic launches Claude plugins with 10,000+ tools across all plans](https://claude.ai/plugins)** — _AlphaSignal · Nov 24_. — Connectors and skills have merged into a single Plugins page inside Claude.
  - Live on Free, Pro, Max and Ultra; Team and Enterprise are coming soon
  - A plugin can be a single connector, a single skill, or several bundled
  - Directory submissions are checked and safety-scanned before listing
